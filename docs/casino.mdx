## 💰 ペイテーブル（配当倍率）

| 役 | 配当 |
|----|------|
| **ジャックポット**（最高シンボル×3） | ベット額の **100倍** |
| **金トリプル** | 40倍 |
| **エメラルドトリプル** | 12倍 |
| **鉄トリプル** | 5倍 |
| **石炭トリプル** | 2.5倍 |
| **2つ揃い** | 1.0倍（ベット額が戻る） |

## 🎲 遊び方

<Steps>
  <Step>**カジノエリアに行く**</Step>
  <Step>**スロットマシンを右クリック** → ベット額を入力</Step>
  <Step>**リールが回転** → 3つのシンボルが揃うと配当獲得</Step>
</Steps>

<Callout type="warn">
  カジノはあくまで **遊び** です。CCの使いすぎにご注意ください。
</Callout>
