  `/rtp` でワールド上のランダム地点にテレポートできます。**既存の町の中・溶岩・空中・海中** は避けて陸地のみが選ばれるため、新規拠点探しや資源採集に安心して使えます。
</Callout>

## 🎲 ランダムテレポート (RTP)

`/rtp` コマンドで、ワールド上のランダムな場所にテレポートできます。新規プレイヤーが拠点を作るための未開拓地を探したり、冒険のスタート地点を選ぶのに便利です。

***

## 🧭 基本コマンド

| コマンド  | 種別      | 説明                |
| ----- | ------- | ----------------- |
| /rtp  | command | 現在のワールドでランダムテレポート |
| /wild | command | エイリアス（同じ機能）       |

***

## 📋 仕様

| 項目      | 種別   | 説明                           |
| ------- | ---- | ---------------------------- |
| テレポート範囲 | spec | ワールド境界（チャンキー設定）の中からランダムに選ばれる |
| 町の中     | spec | 既存の町の範囲外に限定（Towny連携）         |
| 危険な場所   | spec | 溶岩・空中など安全でない場所にはテレポートしない     |
| 海・水中    | spec | 海中にはテレポートせず、自動で陸地を選択         |
| クールダウン  | spec | 連続使用には数秒〜数十秒のクールダウンあり        |

<Callout type="info">
  他プレイヤーの**町の中**にはテレポートしません。安心して使えます。
</Callout>

***

## 💡 使い方のコツ

<Steps>
  <Step>
    ### 新規拠点を探す

    複数回 `/rtp` を実行して気に入った場所を見つけましょう。
  </Step>

  <Step>
    ### 資源採集に行く

    未開拓のチャンクを開拓できるので、新鮮な資源スポットを見つけられます。
  </Step>

  <Step>
    ### クールダウンに注意

    連続使用には **クールダウン**（数秒〜数十秒）があります。
  </Step>
</Steps>

***

## 📘 チュートリアルとの連携

新規プレイヤーは、スポーンの[チュートリアル](/docs/home#チュートリアル)を完了すると **自動的に `/rtp`** が実行され、初期拠点候補にテレポートされます。
