**/home** で自分のテレポート地点を保存（基本5個・ccで追加購入可能）、**/tpa** で他プレイヤーとの相互テレポートが可能です。初回参加時はスポーンに **13問のチュートリアル** が用意されています。
</Callout>

## 🏠 ホーム機能

`/home` で自分専用のテレポート地点を保存・管理できる機能です。家・農場・拠点などをワンタッチで行き来できます。

---

### 基本的な使い方

<Tabs items={['ホーム (/home)', 'テレポート申請 (/tpa)']}>
<Tab value="ホーム (/home)">

| コマンド | 種別 | 説明 |
|---|---|---|
| /home | command | ホームGUIを開く（一覧から選んでテレポート） |
| /sethome &lt;名前&gt; | command | 現在地をホームとして登録 |
| /delhome &lt;名前&gt; | command | ホームを削除 |

ホーム名は **英数字・日本語・記号（`_` `-`）のみ、16文字以内** で指定できます。

ホーム名を変えたいときは、`/home` で開いたGUIの **金床アイコン** から変更してください（名前変更用のコマンドはありません）。

</Tab>
<Tab value="テレポート申請 (/tpa)">

他のプレイヤーに自分の場所までのテレポートを依頼できます。

| コマンド | 種別 | 説明 |
|---|---|---|
| /tpa &lt;プレイヤー&gt; | command | 相手の場所へテレポート申請を送る |
| /tpahere &lt;プレイヤー&gt; | command | 相手を自分の場所に呼ぶ申請を送る |
| /tpaccept | command | 受信したリクエストを承認 |
| /tpdeny | command | 受信したリクエストを拒否 |

リクエストの **有効期限は30秒** です。

<Callout type="info">
TPA受信時はGUIが自動で開きます（無効化したい場合は運営に相談してください）。
</Callout>

</Tab>
</Tabs>

---

### ホーム上限

ホームは基本 **5個** まで登録できます。上限は **cc を使って追加購入** できます。

| 追加スロット | 価格 |
|---|---|
| +2個 | 3,000 cc |
| +15個 | 22,500 cc |

---

### テレポート時の挙動

- テレポートには **3秒** かかります
- その間に **移動するとキャンセル** されます
- テレポート先が危険な地形でも **そのままテレポートします**（落下や溶岩には注意してください）

---

## 📘 チュートリアル

CarrotCraftに**初めて参加した方**は、スポーン地点に設置されている**チュートリアル**で遊び方を学べます。

<Callout type="info">
ゲートエリアに入ると、**13問のクイズ形式チュートリアル** が始まります。修了すると `/rtp` で未開拓地へランダムテレポート、サバイバル開始です。
</Callout>

### 仕組み

<Steps>
<Step>
### スポーンのチュートリアルゲートに入る

CarrotCraftに初めて参加すると、スポーン地点のゲートエリアへ自動で案内されます。
</Step>
<Step>
### 13問のクイズに回答

以下の13テーマがクイズ形式で出題されます：

1. CarrotCraftへようこそ - 参加できるエディションについて
2. ルールとMOD - 禁止事項・許可されているMOD
3. チャットの使い方 - グローバル/タウン/ネーション
4. 通貨とCarrotMarket - お金の稼ぎ方
5. 町の作り方 - `/t new` の使い方
6. 町の維持 - 維持費と土地拡張
7. プレイヤーショップ - QuickShopの使い方
8. PvPについて - `/pvp` 切替と自己責任
9. 窃盗・荒らし - 禁止事項
10. バグ報告とアカウント - 1人1アカウント
11. 困ったとき - Discordチケット
12. 町に参加しよう - `/t list` の使い方
13. 町に入ったらやること - プロット取得
</Step>
<Step>
### `/rtp` で未開拓地へ

修了すると、`/rtp` で未開拓地にランダムテレポートしてサバイバル開始です！
</Step>
</Steps>

<Callout type="info">
2回目以降の参加では、ゲートはスキップされてそのままサバイバルに参加できます。
</Callout>
