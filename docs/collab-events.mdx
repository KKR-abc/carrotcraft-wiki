## 📌 イベントの進め方

<Steps>
<Step>
### アイデアを提案
チケットでイベント案を送ってください（必要な項目は後述）。
</Step>
<Step>
### 運営内で審査
チケットでいただいたアイデアは、**運営内で話し合いのうえ審査**します。
</Step>
<Step>
### 制作・準備
- **サバイバルで作れない・プラグイン等が必要な場合は運営が作成**します
- プラグイン制作・リソースパック制作など、得意な方は**鯖民側からの参加も大歓迎**です
</Step>
<Step>
### チーム編成は柔軟に
- 自分の町のメンバーと作る
- 制作チームを新たに募集する
- 運営とプレイヤーで混成チームを作る　など
</Step>
<Step>
### 開催
日時を調整して開催。終わったら振り返りも。
</Step>
</Steps>

## 💡 提案するときに書いてほしいこと

チケットを作成する際、以下の項目を含めていただけるとスムーズです。

| 項目 | 必要度 | 内容 |
|---|---|---|
| 🎯 イベント概要 | 必須 | どんなイベントか／何をするのか |
| 👥 参加者 | 必須 | 誰が参加できるか（全員／応募制／町単位 など） |
| 🤝 必要な協力 | 必須 | 運営に作ってほしいもの（建築物・プラグイン・賞品 など） |
| 🗓️ 希望時期 | 推奨 | 開催したい日時の目安 |
| 🏆 賞品案 | 任意 | あれば（運営と相談しながら決めてもOK） |

## 📝 提案方法

[CarrotCraft Discord](https://discord.gg/EKUPDxXaqb) のチケットチャンネルから新規チケットを作成し、上記の項目を記入して送信してください。運営から内容について確認・相談のご連絡をします。
