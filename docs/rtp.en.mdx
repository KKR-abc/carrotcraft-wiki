## 🎲 Random Teleport (RTP)

The `/rtp` command teleports you to a random location in the world. Use it to find unsettled land for a new base, or to start an adventure in a fresh area.

---

## 🧭 Basic Commands

| Command | Type | Description |
|---|---|---|
| /rtp | command | Random teleport in the current world |
| /wild | command | Alias (same function) |

---

## 📋 Specifications

| Item | Type | Description |
|---|---|---|
| Range | spec | Random location within the world border (Chunky setting) |
| Towns | spec | Always outside any existing town's borders (Towny integration) |
| Unsafe spots | spec | Will not teleport into lava or mid-air |
| Oceans | spec | Will not drop you into oceans — auto-selects land |
| Cooldown | spec | Repeated use has a cooldown of a few to a few dozen seconds |

<Callout type="info">
You won't be teleported into other players' **towns**. Use `/rtp` with peace of mind.
</Callout>

## 💡 Tips

Find untouched chunks to harvest fresh materials.

<Step>

</Step>

## 📘 Tutorial Integration

New players who complete the [Tutorial](/docs/home#tutorial) at spawn are **automatically teleported** to a candidate base location via `/rtp`.
