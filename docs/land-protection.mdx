<Callout type="info" title="このページの読み方">
**土地保護（CarrotGuard）** で、自分の土地を **範囲ごと** 守る方法をまとめています。木のクワで2点を選び、`/guard` から作成します。チェスト単体を守る[チェスト保護](/docs/bolt)や、町全体を守る[Towny](/docs/towny)とは別の仕組みです。
</Callout>

## 🛡 土地保護とは？

**木のクワで囲った範囲** を丸ごと保護し、他のプレイヤーによる破壊・設置・盗難などを防げる機能です。保護には2種類あります。

<Cards>
<Card title="初心者保護" description="サーバー参加から一定期間だけ使える無料の保護。まず自分の拠点を守るための入門用。" />
<Card title="街保護" description="町長・副町長が作れる保護。住民数に応じてサイズ上限が広がり、費用がかかります。" />
</Cards>

<Callout type="warn" title="他人の建築物を無断で保護しないこと">
他人の建築物・土地を、本人の許可なく自分の保護範囲に含める行為は **禁止** です。発覚した場合、当該保護は **強制解除** され、**処罰の対象** となります（利用規約 3.1）。
</Callout>

## ✏️ 作り方

<Steps>
<Step>
### 木のクワを用意する

範囲選択には **ただの木のクワ** を使います。クラフトして手に持つだけでOK（専用アイテムの配布はありません）。
</Step>
<Step>
### 2点を選択する

木のクワを持って、**左クリックで1点目**・**右クリックで2点目** を指定します。選んだ範囲はパーティクルの枠で表示されます（高さは全域が対象）。
</Step>
<Step>
### `/guard` で作成する

`/guard` を実行し、**「選択範囲で作成」** をクリック。確認画面で **種別（初心者保護／街保護）** ・サイズ・費用・作成可否を確認して **確定** します。

<Callout type="info" title="両方作れる人は切り替えできます">
初心者期間中の町長・副町長など、両方の資格がある場合は、確認画面上部のボタンで **初心者保護 ⇔ 街保護** を切り替えて作成できます。
</Callout>
</Step>
</Steps>

## ⚙️ 保護の設定（トグル）

`/guard` → 保護をクリック → **設定（トグル）** から、その保護の中で以下をON（制限）／OFF（許可）で切り替えられます。

| トグル | ON にすると |
|---|---|
| ブロックの破壊 | メンバー以外は壊せない |
| ブロックの設置 | メンバー以外は置けない |
| 使用・チェストを開く | メンバー以外は使えない／開けない |
| 攻撃（PvP・動物） | 範囲内での PvP・動物への攻撃を禁止 |
| モンスターの湧き | 範囲内にモンスターが湧かない |
| 火の延焼 | 火が燃え広がらない |

破壊・設置・使用は既定でON（保護されている状態）です。

---

## 👥 メンバーを追加する

保護の管理画面 → **メンバー追加** から、一緒に建築できる人を追加できます。

- **オンラインの人**：一覧から頭アイコンをクリックして追加
- **オフラインの人**：**金床** ボタンで名前を入力して追加（未参加のプレイヤーも指定可）

## 🚫 保護を作れない条件（作れない場所）

以下の場所・状況では保護を作成できません。

<Accordions>
<Accordion title="共通（初心者保護・街保護とも）">
- 既存の保護や、**Towny の町の区画と重なる** 場所
- **近く（半径150ブロック以内）に既に町がある** 場所
- 他人の建築物・土地（無断保護は規約違反）
</Accordion>
<Accordion title="初心者保護のとき">
- 初心者期間（参加から14日）を **過ぎている**
- 初心者保護の **個数上限（3個）** を超える
- **サイズ上限（32×32）** を超える
</Accordion>
<Accordion title="街保護のとき">
- **町長・副町長ではない**
- 町の合計保護面積が **サイズ上限（住民数÷2 × 256ブロック²）** を超える
- **所持金（CC）が不足** している
</Accordion>
</Accordions>

## 🗑 保護が削除される条件

<Callout type="warn" title="初心者保護は自動で消えます">
初心者保護は **参加から一定期間（14日）で自動的に削除** されます。期限が近づくと警告が届きます。消える前に **街を作る** か、**既存の街に保護してもらう** ようにしてください。
</Callout>

- **初心者保護の期限切れ**：参加から14日経過で自動撤去
- **町の区画と重なった**：あとから Towny の町の区画と重なった保護は自動撤去
- **自分で削除**：管理画面 → 削除 → 確認画面で「削除する」
- **規約違反**：他人の建築物の無断保護など、違反が確認された保護は運営が強制削除

<Callout type="info" title="荒らされても復旧できます">
保護が外れて荒らされた場合でも、**運営に報告すればロールバックで復元** できることがあります（[補填・ロールバック](/docs/rules#6-補填ロールバック)）。
</Callout>

## 📋 コマンド

| コマンド | 内容 |
|---|---|
| `/guard` | 保護メニュー（一覧・作成・管理） |
| `/guard tool` | 選択方法の案内（棒＝木のクワの使い方） |
| `/guard create` | 選択範囲から作成（GUIを開かず作成） |
| `/guard list` | 自分の保護一覧 |

管理者向けには `/guardadmin`（一覧・情報・テレポート・フラグ切替・削除など）があります。
