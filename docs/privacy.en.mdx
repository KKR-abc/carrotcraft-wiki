## 📋 CarrotCraft Privacy Policy

This policy describes how personal information is handled across CarrotCraft's Minecraft server and Discord server (collectively "the Service").

---

## 📥 1. Data We Collect

### Minecraft Server

| Data | Purpose |
|------|---------|
| IP Address | VPN detection, anti-griefing, ban management |
| MCID / UUID | Player identification |
| Chat logs (including `/msg`, etc.) | Investigation of misconduct, dispute resolution |
| Game data (coordinates, inventory, economy, etc.) | Server operation, rollback support |
| Login / logout times | Activity records, misconduct investigation |

### Discord Server

| Data | Purpose |
|------|---------|
| Discord User ID | Ticket handling, punishment management |
| Support ticket content | Record of dispute resolution |

---

## 🎯 2. How We Use Your Data

Collected data is used only for the following purposes:

- **Anti-griefing & misconduct prevention**: VPN detection and ban management using IP addresses
- **Player protection**: Investigation of harassment and other issues using chat logs
- **Server operation**: Game data management, rollbacks, economy system maintenance
- **Support**: Resolving issues through the ticket system

---

## 🤝 3. Disclosure to Third Parties

Personal information will **not be disclosed or shared with any third party unless required by law.**

---

## 🔒 4. Data Management

- Collected data is accessible only to staff members
- Data is retained for as long as necessary for anti-griefing and server operation purposes
- Data that is no longer needed will be appropriately deleted

---

## 📨 5. Contact

For questions about this policy or inquiries regarding your data, please use the ticket system on [Discord](https://discord.gg/EKUPDxXaqb).

---

## 📝 6. Policy Changes

This policy may be changed without prior notice. Updated policies take effect upon publication on this site.
