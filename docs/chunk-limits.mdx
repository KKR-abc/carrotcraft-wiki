<Callout type="info" title="チャンク制限について">
サーバーの安定性を維持するため、1チャンク（16×16ブロック）あたりに設置できるブロック数やエンティティ数に上限があります。上限を超えると設置・スポーンが制限されます。
</Callout>

## 🐾 エンティティ上限

エンティティ（Mob・アイテム等）の上限です。判定は**そのチャンクと周囲1チャンク（3×3チャンク）の合計**で行われます。

種類ごとの個別上限はなく、**カテゴリごとの合計**で制限されます（村人のみ個別上限あり）。

| カテゴリ | 合計上限 |
| --- | --- |
| 動物 | 70 |
| モンスター | 140 |
| NPC | 60 |
| 水生Mob | 20 |
| 環境Mob | 20 |
| その他（防具立て・額縁など） | 500 |

<Callout type="info" title="村人のみ個別上限">
村人は取引施設などで集中しやすいため、カテゴリとは別に **1エリアあたり 40体** の個別上限があります。
</Callout>

## ⚠️ 上限に達した場合

<Callout type="warn" title="エンティティは自動的に除去されます">
**ブロック**: 上限に達するとそれ以上設置できなくなり、画面に通知が表示されます。

**エンティティ**: 上限を超えた分は自動的に除去されます。名前付きのエンティティは優先的に保護されます。
</Callout>

<Callout type="info" title="設計のヒント">
大規模な装置を作る際はチャンクをまたいで分散させることで、上限に引っかかりにくくなります。
</Callout>

## ❓ よくある質問

<Accordions>
<Accordion title="チャンクの境界はどうやって確認できる？">
F3 + G キー（Java版）でチャンク境界線を表示できます。1チャンクは 16×16 ブロックです。
</Accordion>
<Accordion title="名前付きMobは絶対に消えない？">
名前付きエンティティは優先的に保護されますが、極端に超過した場合は対象になることがあります。
</Accordion>
<Accordion title="上限を引き上げてもらえる？">
パフォーマンスの観点から、原則として個別の引き上げは行っていません。配置を分散することで対応してください。
</Accordion>
</Accordions>
