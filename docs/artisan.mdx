## 🧰 使い方

<Steps>
  <Step>
    **`/assyuku` を開く**

    圧縮職人のハブが開きます。残高・納品ボックス・価格表・開拓 (購入所) がここに揃っています。
  </Step>
  <Step>
    **納品ボックスに素材を入れて、閉じる**

    閉じた瞬間に納品されて、圧縮ポイントが入ります。**シュルカーごと入れれば中身も納品されます**。
  </Step>
  <Step>
    **「開拓」から購入する**

    移動 (境界を動かす) か、リセット (作り直す) を選びます。買うと全サーバーに告知が流れます。
  </Step>
</Steps>

## 🪙 納品について

| 項目 | 種別 | 説明 |
| --- | --- | --- |
| 対象アイテム | spec | 丸石・石・深層岩・土・砂・砂利・ネザーラック・原木・石炭・鉄・金・銅・レッドストーン・ラピス・クォーツ・エメラルド・ダイヤ など |
| 対象外アイテム | spec | 名前付き・エンチャント付き・カスタム品はそのまま返却されます |
| シュルカー | spec | 中身が納品され、シュルカー本体は返ってきます |
| 1日の上限 | spec | 1日に納品できる量に上限があります。残りはハブ画面に表示されます |
| 上限のリセット | spec | 毎日 4:00 (日本時間) |

<Callout type="info" title="値段は変動します">
  よく納品された素材は **単価が下がり**、しばらく誰も納品しなければ **元の値段に戻っていきます**。今いくらなのかは `/assyuku` の **価格表** で確認できます。売る人が多い素材ほど安くなる、という素直な仕組みです。
</Callout>

## 🧱 圧縮のしかた

対象素材は **作業台で圧縮できます**。9個を 3×3 に並べると、1段上の「圧縮ブロック」が1個できます。これを7段まで繰り返せます。

<Steps>
  <Step>
    **9個 → 1個**

    作業台に同じ素材を 9 個並べる（3×3 を全部埋める）と、圧縮1段目が 1 個できます。
  </Step>
  <Step>
    **さらに重ねる**

    できた圧縮ブロック 9 個をまた 3×3 に並べると 2 段目。**最大 7 段**まで。
  </Step>
  <Step>
    **戻すときは 1個 → 8個**

    圧縮ブロックを作業台に 1 個置くと、1段下が 8 個に戻ります。
  </Step>
</Steps>

<Callout type="warn" title="戻すと 1 個ぶん減ります">
  圧縮は **9個 → 1個**、解凍は **1個 → 8個**。往復すると 1 個ぶん失われます（圧縮税）。圧縮ブロックの価値も、この解凍後の量で数えます（1段目 = 8個ぶん、7段目 = 2,097,152個ぶん）。
</Callout>

<Callout type="error" title="圧縮ブロックは置かない・普通のクラフトに使わない">
  圧縮ブロックは見た目が元の素材と同じですが、中身は何十万個ぶんの価値を持っています。**設置すると価値が消えます**。圧縮・解凍・納品以外の用途では使わないでください（普通のクラフトに混ぜようとすると弾かれます）。
</Callout>

## ⚖️ 変換効率 — 圧縮してから納品すると損します

納品するときの効率は、**その物が何段圧縮されているか**で変わります。

| 納品するもの | 種別 | 変換効率 |
| --- | --- | --- |
| 圧縮していない素材（手持ち） | spec | **100%** |
| 圧縮1段目〜6段目 | spec | 段が上がるほど下がる（線形） |
| 圧縮7段目（最上段） | spec | **75%** |
| シュルカーごと投入 | spec | 中身の段に関わらず **一律 75%** |

<Callout type="warn" title="つまり">
  **一番得なのは、圧縮せずにそのまま納品すること**です。圧縮は「持ち運び」と「圧縮ランク・バッジ」のための道で、ポイント効率を上げる道ではありません。シュルカーごと放り込むのは楽ですが、その手軽さの対価として一律 75% になります。
</Callout>

## 🗺️ 開拓 — 移動とリセット

資源ワールドには **境界 (ボーダー)** があります。ポイントを使って、この境界を動かしたり、ワールドごと作り直したりできます。

### 移動 (境界をずらす)

境界の **大きさはそのまま** に、指定した方向へまるごとスライドします。前方に手つかずの土地が開放され、後方は圏外になります。

| 項目 | 種別 | 説明 |
| --- | --- | --- |
| 単位 | spec | 1個 = 1,000ブロック。1回に最大20個まで指定できます |
| 方向 | spec | 最前線 / 北 / 東 / 南 / 西 から選びます |
| 効くまで | spec | 買ってから **1時間後** に実際に動きます |
| 次に買えるまで | spec | 購入した瞬間から **2時間** |

### リセット (ワールドを作り直す)

<Callout type="warn">
  **リセットの購入は現在一時停止中です。** 購入画面には「現在停止中です」と表示され、買えません。
</Callout>

資源ワールドを **新しい地形で丸ごと作り直します**。境界も初期状態に戻ります。

| 項目 | 種別 | 説明 |
| --- | --- | --- |
| 効くまで | spec | 買ってから **2時間後** に作り直されます |
| 次に買えるまで | spec | 購入した瞬間から **5時間** |
| 持ち物 | spec | 手持ち・経験値・エンダーチェストは **そのまま残ります** |
| 拠点 | spec | 資源ワールドに置いた物は **すべて消えます** |

<Callout type="error" title="資源ワールドに大事な物を置かないでください">
  移動でもリセットでも、資源ワールドの地形は変わります。**置いたチェストや建築は戻りません**。拠点はメインサーバーに作り、資源ワールドは掘る場所として使ってください。
</Callout>

***

## ⏰ 告知とカウントダウン

購入すると **全サーバーに告知が流れます**。「誰が・どのワールドを・どの方向へ何ブロック動かすか」がその場で分かります。

実行までの残り時間は、**45分前 → 30分前 → 15分前 → 10分前 → 5分前 → 2分前 → 1分前 → 30秒前** と刻まれ、最後は **10 → 5 → 3 → 2 → 1** の秒読みが入ります。**この間に資源を回収してください。**

<Callout type="info" title="リセット中は安全な待機空間へ">
  リセットが実行される瞬間、資源ワールドに居た人は **何も無い安全な空間** に一時退避します。ダメージは受けませんし、落下もしません。完了すると **新しいワールドのどこかへ自動で転送** されます。
</Callout>

## ❓ よくある質問

<Accordions>
  <Accordion title="納品したのに何も起きませんでした">
    その素材が **対象外** か、**1日の上限** に達している可能性があります。対象外のアイテムはそのまま返却されます。残りの上限は `/assyuku` のハブ画面で確認できます。
  </Accordion>
  <Accordion title="圧縮ポイントをお金に換えられますか？">
    できません。圧縮ポイントは資源ワールドの開拓にしか使えません。他のプレイヤーへ **送る** ことはできます (`/assyuku pay`)。
  </Accordion>
  <Accordion title="買ったのにすぐ動きません">
    移動は1時間後、リセットは2時間後に実行されます。**回収の時間** を確保するためです。残り時間は資源ワールドで `/carrotborder eta` を実行すると確認できます（国家では使えません）。
  </Accordion>
  <Accordion title="資源ワールドに置いた拠点はどうなりますか？">
    移動で圏外になった土地も、リセットで作り直された土地も、**元には戻りません**。資源ワールドは掘るための場所です。大事な物はメインサーバーに置いてください。
  </Accordion>
  <Accordion title="価格が昨日と違います">
    素材の単価は **納品された量で変動** します。たくさん納品された素材は安くなり、誰も納品しなくなると元の値段へ戻っていきます。最新の値段は価格表で確認できます。
  </Accordion>
</Accordions>
