<Callout type="info" title="圧縮職人とは？">
  余った石や土を **圧縮ポイント** に変えて、みんなで **資源ワールドを広げたり作り直したり** できる仕組みです。掘り尽くした資源ワールドを、自分たちの手で更新できます。
</Callout>

## 📦 かんたんに言うと

<Cards>
  <Card title="① 素材を納品する" description="丸石・鉄・ダイヤなどを納品ボックスに入れて閉じるだけ。圧縮ポイント (pt) が貯まります。" />
  <Card title="② ポイントで開拓を買う" description="貯めたポイントで、資源ワールドの境界を動かす『移動』か、丸ごと作り直す『リセット』を買えます。" />
  <Card title="③ みんなに反映される" description="買った操作はサーバー全体に告知され、決まった時間に実行されます。新しい土地がみんなに開放されます。" />
</Cards>

<Callout type="warn" title="圧縮ポイントはお金ではありません">
  圧縮ポイント (pt) は **CC (通貨) に換金できません**。使い道は資源ワールドの開拓だけです。
</Callout>

***

## 🧰 使い方

<Steps>
  <Step>
    **`/assyuku` を開く**

    圧縮職人のハブが開きます。残高・納品ボックス・価格表・開拓 (購入所) がここに揃っています。
  </Step>
  <Step>
    **納品ボックスに素材を入れて、閉じる**

    閉じた瞬間に納品されて、圧縮ポイントが入ります。**シュルカーごと入れれば中身も納品されます**。
  </Step>
  <Step>
    **「開拓」から購入する**

    移動 (境界を動かす) か、リセット (作り直す) を選びます。買うと全サーバーに告知が流れます。
  </Step>
</Steps>

***

## 🪙 納品について

| 項目 | 種別 | 説明 |
| --- | --- | --- |
| 対象アイテム | spec | 丸石・石・深層岩・土・砂・砂利・ネザーラック・原木・石炭・鉄・金・銅・レッドストーン・ラピス・クォーツ・エメラルド・ダイヤ など |
| 対象外アイテム | spec | 名前付き・エンチャント付き・カスタム品はそのまま返却されます |
| シュルカー | spec | 中身が納品され、シュルカー本体は返ってきます |
| 1日の上限 | spec | 1日に納品できる量に上限があります。残りはハブ画面に表示されます |
| 上限のリセット | spec | 毎日 4:00 (日本時間) |

<Callout type="info" title="値段の決まり方 — 素材ごとの「枠」">
  素材ごとに **その日に定価で買い取れる量 (枠)** があります。

  - 枠が残っているうちは **定価**
  - 使い切ると **半額**
  - それも使い切ると、その素材はその日はおしまい (翌日また売れます)

  枠は **時間とともに少しずつ回復** します。朝に一斉リセットではないので、早起きした人が有利ということはありません。

  みんなが同じ素材を納品すると、その素材の枠は先に尽きます。逆に **あまり納品されていない素材は枠が残っている** ので、そちらを狙うと得です。今いくらなのかは `/assyuku` の **価格表** で確認できます。
</Callout>

## 🧱 圧縮のしかた

対象素材は **作業台で圧縮できます**。9個を 3×3 に並べると、1段上の「圧縮ブロック」が1個できます。これを **11段** まで繰り返せます。

<Steps>
  <Step>
    **9個 → 1個**

    作業台に同じ素材を 9 個並べる（3×3 を全部埋める）と、圧縮1段目が 1 個できます。
  </Step>
  <Step>
    **さらに重ねる**

    できた圧縮ブロック 9 個をまた 3×3 に並べると 2 段目。**最大 11 段**まで。
  </Step>
  <Step>
    **戻すときは 1個 → 8個**

    圧縮ブロックを作業台に 1 個置くと、1段下が 8 個に戻ります。
  </Step>
</Steps>

<Callout type="warn" title="戻すと 1 個ぶん減ります">
  圧縮は **9個 → 1個**、解凍は **1個 → 8個**。往復すると 1 個ぶん失われます（圧縮税）。
</Callout>

<Callout type="error" title="圧縮ブロックは置かない・普通のクラフトに使わない">
  圧縮ブロックは見た目が元の素材と同じですが、中身は何万個ぶんもの価値を持っています。**設置すると価値が消えます**。圧縮・解凍・納品以外の用途では使わないでください（普通のクラフトに混ぜようとすると弾かれます）。
</Callout>

***

## ⚖️ 圧縮すると納品で得します

以前は「圧縮すると損」でしたが、**逆になりました**。納品するときは、**圧縮に使った個数**で数えたうえに、段数に応じたボーナスが乗ります。

| 納品するもの | 種別 | もらえる量 |
| --- | --- | --- |
| 圧縮していない素材（手持ち） | spec | そのまま **100%** |
| 圧縮1段目 | spec | **+11%**（9個を1回圧縮＝10個ぶん） |
| 圧縮2段目 | spec | **+22%** |
| 圧縮3段目 | spec | **+33%** |
| 圧縮4段目 | spec | **+44%** |
| 圧縮5段目以上 | spec | **+50%**（ここで頭打ち） |
| シュルカーごと投入 | spec | 中身の段に関わらず **一律 75%**（ボーナスは付きません） |

<Callout type="warn" title="つまり">
  **手で圧縮してから納品するのが一番得** です。まとめてシュルカーごと放り込むのは楽ですが、その手軽さの対価として一律 75%（ボーナスなし）になります。段ごとの実際のポイントは `/assyuku` の価格表で確認できます。
</Callout>

## 🗺️ 開拓 — 移動とリセット

資源ワールドには **境界 (ボーダー)** があります。ポイントを使って、この境界を動かしたり、ワールドごと作り直したりできます。

### 移動 (境界をずらす)

境界の **大きさはそのまま** に、指定した方向へまるごとスライドします。前方に手つかずの土地が開放され、後方は圏外になります。

| 項目 | 種別 | 説明 |
| --- | --- | --- |
| 単位 | spec | 1個 = 1,000ブロック。1回に最大20個まで指定できます |
| 方向 | spec | 最前線 / 北 / 東 / 南 / 西 から選びます |
| 効くまで | spec | 買ってから **1時間後** に実際に動きます |

### リセット (ワールドを作り直す) — 予約制

リセットは **時間を選ぶ形ではなく、その日の 18:00 に固定** されています。

| 時刻 | 種別 | 何が起きるか |
| --- | --- | --- |
| 買った瞬間 | spec | 予約が確定し、**そのワールドには入れなくなります**（裏で新しい地形の準備が始まります） |
| 15:00 | spec | その日の予約の **締切**。これを過ぎた購入は翌日ぶんになります |
| 17:00 | spec | 新しいワールドへ切り替わり、**購入者と、購入者が選んだ人だけ**入れます |
| 18:00 | spec | **全員入場可**。同時に境界が広がり始め、30分かけて広がりきります |

<Callout type="warn" title="予約は1日1件・早い者勝ち">
  同じ日に予約を重ねることはできません。**予約した瞬間からそのワールドには入れなくなります。** 資源ワールドに貴重品を置かないでください（自己責任となり、運営では補填できません）。
</Callout>

### 先行入場の同伴者

買った人は、17:00 から一緒に入る人を選べます。`/frontier reserve` で画面が開くので、顔をクリックして選ぶだけです（**20人まで**）。全体公開より早く、みんなで物資集めができます。

### エンダードラゴンの卵

エンドは **毎月1日に運営がリセット** します。**卵が落ちるのはこの回のドラゴンだけ** で、購入したリセットでは出ません。

| 項目 | 種別 | 説明 |
| --- | --- | --- |
| 持ち物 | spec | 手持ち・経験値・エンダーチェストは **そのまま残ります** |
| 拠点 | spec | 資源ワールドに置いた物は **すべて消えます** |

<Callout type="error" title="資源ワールドに大事な物を置かないでください">
  移動でもリセットでも、資源ワールドの地形は変わります。**置いたチェストや建築は戻りません**。拠点はメインサーバーに作り、資源ワールドは掘る場所として使ってください。
</Callout>

## 🏘️ 街のみんなでポイントを貯める

`/frontier town` で **街の財布** が使えます。

- **入金** … その街の住人なら誰でも
- **引き出し** … 町長と、町長が選んだ協力者だけ

みんなで貯めて、街として開拓を買えます。

***

## ⏰ 告知とカウントダウン

移動を購入すると **全サーバーに告知が流れます**。「誰が・どのワールドを・どの方向へ何ブロック動かすか」がその場で分かります。

実行までの残り時間は、**45分前 → 30分前 → 15分前 → 10分前 → 5分前 → 2分前 → 1分前 → 30秒前** と刻まれ、最後は **10 → 5 → 3 → 2 → 1** の秒読みが入ります。**この間に資源を回収してください。**

リセットは予約された時点で告知が流れ、切り替わる時刻も決まっています（上の表を参照）。

## 💬 コマンド

| コマンド | 種別 | 説明 |
| --- | --- | --- |
| /assyuku | command | 圧縮職人のハブを開く (納品・価格表・開拓) |
| /assyuku pay &lt;名前&gt; &lt;pt&gt; | command | 圧縮ポイントを他のプレイヤーに送る |
| /assyuku top [人数] | command | 圧縮ポイントのランキング (自分の順位も出ます) |
| /assyuku help | command | 使い方の一覧 |
| /frontier balance | command | 圧縮ポイントの残高 |
| /frontier history | command | ポイントの増減履歴 |
| /frontier top | command | 残高ランキング |
| /frontier reserve | command | リセット予約の確認・先行入場の同伴者を選ぶ |
| /frontier town | command | 街の財布 (入金・引き出し・協力者) |
| /carrotborder eta | command | 進行中の移動 / リセットの残り時間（**資源ワールドでのみ使用可**） |

## ❓ よくある質問

<Accordions>
  <Accordion title="納品したのに何も起きませんでした">
    その素材が **対象外** か、**1日の上限** に達している可能性があります。対象外のアイテムはそのまま返却されます。残りの上限は `/assyuku` のハブ画面で確認できます。
  </Accordion>
  <Accordion title="圧縮してから納品した方がいいですか？">
    はい。手で圧縮したぶんは段数に応じてボーナスが付きます（5段以上で頭打ち）。ただし **シュルカーごと放り込んだぶんはボーナスの対象外** で、一律 75% です。
  </Accordion>
  <Accordion title="圧縮ポイントをお金に換えられますか？">
    できません。圧縮ポイントは資源ワールドの開拓にしか使えません。他のプレイヤーへ **送る** ことはできます (`/assyuku pay`)。
  </Accordion>
  <Accordion title="リセットを買ったのにすぐ変わりません">
    リセットは **その日の18:00** に実行されます（15:00 が締切。過ぎた購入は翌日ぶん）。17:00 から購入者と同伴者だけが先に入れます。移動は買ってから1時間後で、残り時間は資源ワールドで `/carrotborder eta` を実行すると確認できます（国家では使えません）。
  </Accordion>
  <Accordion title="資源ワールドに置いた拠点はどうなりますか？">
    移動で圏外になった土地も、リセットで作り直された土地も、**元には戻りません**。資源ワールドは掘るための場所です。大事な物はメインサーバーに置いてください。
  </Accordion>
  <Accordion title="価格が昨日と違います">
    素材ごとに「その日に定価で買い取れる枠」があり、枠が尽きると半額、さらに尽きるとその日は買い取り終了になります。枠は時間とともに回復します。最新の単価は価格表で確認できます。
  </Accordion>
</Accordions>
