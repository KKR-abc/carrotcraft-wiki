## ⚙️ Basic Commands

| Command | Description |
|---------|-------------|
| `/rtp` | Random teleport |
| `/rule` | View server rules (`/rule 1`–`/rule 8` for individual sections) |
| `/gui toggledeath` | Toggle the auto-given GUI book on death |
| `/gui give` | Obtaining the GUI book | 

## 🏠 Home Commands

| Command | Description |
|---------|-------------|
| `/home` | Open the Home GUI (view, teleport, set, and delete homes all from the GUI) |
| `/sethome [name]` | Set the current location as the home location |
| `/delhome <name>` | Delete the specified home |

## 💰 Economy Commands

| Command | Description |
|---------|-------------|
| `/bal` | Check balance |
| `/pay <player> <amount>` | Send money |
| `/paytoggle` | Whether or not to accept the remitted funds |
| `/baltop` | Wealth ranking |
| `/market` | Open the CarrotMarket「`/shop`」 |
| `/sellall` | Sell ​​all items placed in the GUI |
| `/trash` | Discard all items placed in the GUI |
| `/qs create <price>` | Create a QuickShop |
| `/qs find <item>` | Search for shops |
| `/auc` | Open the auction house (list items from here) |
| `/auc box` | Collect winnings & refunds (held 7 days) |
| `/auc notify off` | Mute auction notifications |

## ⚔️ PvP Commands

| Command | Description |
|---------|-------------|
| `/pvp` | Toggle PvP on/off |
| `/pvp mode <mode>` | Choose your combat mode (see below) |

| Mode | Allowed attacks |
|---|---|
| `crystal` | Explosives + sword/axe + bow |
| `mace` | Mace + wind charge + axe + bow |
| `sword` | Sword/axe melee only |
| `potion` | Sword/axe + splash potions |
| `all` | Everything (default) |

<Callout type="info">
Damage only applies when **both players' modes allow the attack** (e.g. crystal vs crystal allows explosions; crystal vs sword is melee only). You can't change modes mid-combat (15s cooldown). Your current mode shows on the action bar.
</Callout>

| `/lc` | Local chat |
