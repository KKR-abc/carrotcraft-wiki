<Callout type="info" title="週替わり競争とは">
ある１つのテーマに沿って、1週間他のプレイヤーと採掘数や収穫数を競うものです。
上位 **3位** は賞金をもらえます。
</Callout>

## 🏃 これまでの内容

### 第一回 『ダイヤ採掘数』
### 第二回 『釣り成功回数』
### 第三回 『作物収穫数』
### 第四回 『石系ブロック採掘数』
### 第五回 『古代の残骸採掘数』

## 🏆 報酬

週替わり競争上位3名の入賞者は **メダル** と **賞金** を獲得できます。
| 順位 | 賞金 |
|---|---|
| 1位 | 50,000cc |
| 2位 | 25,000cc |
| 3位 | 10,000cc |

## メダルの使い道
  
<Steps>
  <Step>

### 換金する
  
メダルを10枚集めると、200,000ccと交換することができます。

</Step>
  <Step>

  ### 聖杯と交換する

メダルを3つ集めると、 **石炭の聖杯** と交換できます。  
同ランクの聖杯2個を合わせると、一ランク上の聖杯を作ることができます。  
石炭 → ブロンズ → 鉄 → 金 → ダイヤ → エメラルド → ラピス → レッドストーン

</Step>
  </Steps>

## 👀　順位や内容の確認

ゲーム内でコマンドを使用することで確認できます。
 `/compe` 

<Callout type="warn" title="順位は途中まで">
順位は競争終了が近くなるとわからなくなります。自分が今どのくらいの順位にいるか確認したいなら、早めにしておきましょう。
</Callout>

## ⚠ 注意点
- 採掘数や収穫数において、自身が設置したものをすぐに回収することでは回数は増えません。
- いつ競争が始まるかはわかりません。
- ルールが追加されることもあるので気を付けましょう
