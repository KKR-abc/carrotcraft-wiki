<Callout type="info" title="このページの読み方">
**Bolt** プラグインで、チェスト・ドア・かまど・樽などをロックして他のプレイヤーから守る方法をまとめています。シフト＋右クリック2回でクイックロック、`/lock` でコマンド指定もできます。
</Callout>

## 🔒 チェスト保護とは？

**Bolt** プラグインを使うと、チェスト・ドア・かまど・樽などを **ロック** して他のプレイヤーから守ることができます。

<Callout type="warn" title="町の役職はバイパス可能">
保護を行った場合でも、そのチェストが設置されている **町の市長・副市長・補佐（assistant）は中身の閲覧および破壊が可能** です。

そのため、他の街の範囲内に設置した場合や、後から街の範囲に組み込まれた場合には、中身が見られたり盗まれたりする可能性があります。

**最も確実な盗難対策は、自分の町を建設し、チェストをその範囲内に設置することです。**
</Callout>

## 🛡 ロック方法

<Tabs items={['クイックロック（推奨）', 'コマンドでロック']}>
<Tab value="クイックロック（推奨）">

<Steps>
<Step>
### シフトキーを押しながらブロックを開く

対象のチェスト・ドアなどに対して **シフトを押しながら右クリック**（開く操作）を行います。
</Step>
<Step>
### もう一度同じ操作を繰り返す

**シフト＋右クリックを2回** 連続で行うことで、ブロックが即座に `private` でロックされます。
</Step>
<Step>
### ロックを確認

`/bolt info` でクリックしたブロックの保護情報を確認できます。
</Step>
</Steps>

</Tab>
<Tab value="コマンドでロック">

| コマンド | 説明 |
|---|---|
| `/lock` | 次にクリックしたブロックをロック（プライベート） |
| `/unlock` | ロックを解除 |
| `/bolt modify add normal player <プレイヤー>` | 信頼するプレイヤーを追加 |
| `/bolt modify remove player <プレイヤー>` | 信頼を解除 |
| `/bolt info` | クリックしたブロックのロック情報を表示 |
| `/bolt mode persist` | 連続ロックモードを切り替える |


</Tab>
</Tabs>

## 📦 ロックできるブロック

| カテゴリ | 対象ブロック |
|---|---|
| コンテナ系 | チェスト・トラップチェスト・エンダーチェスト・樽 |
| 加工系 | かまど・燻製器・溶鉱炉・調合台 |
| 搬送系 | ホッパー・ディスペンサー・ドロッパー |
| 開閉系 | ドア・トラップドア・フェンスゲート |
| 掲示系 | 看板・額縁 |
| 装飾系 | ジュークボックス・ロウソク棚（書見台） |
| その他 | シュルカーボックス・装飾陶器 |

---

## 🗝 保護タイプ

タイプ変更は `/lock <タイプ>` で指定できます。

| タイプ | 説明 |
|---|---|
| `private` | 自分のみ使用可能（デフォルト） |
| `display` | 表示のみ。誰でも閲覧可・操作不可 |
| `deposit` | 預け入れのみ可（取り出し不可） |
| `withdrawal` | 引き出しのみ可（預け入れ不可） |
| `public` | 全員使用可能 |

## 👥 信頼プレイヤーの追加

<Steps>
<Step>
### `/bolt modify` コマンドを実行

```
/bolt modify add normal player <プレイヤー名>
```
</Step>
<Step>
### 対象のチェストをクリック

信頼登録したいプレイヤー名を指定後、対象のチェストをクリックすると登録完了です。
</Step>
<Step>
### 権限の種類を変える場合

`normal` の部分を変えると権限が変わります（`admin` なら管理者権限）。
解除するときは `/bolt modify remove player <プレイヤー名>` を実行してから対象をクリックします。
</Step>
</Steps>

---

## 📋 仕様

- 1つのチェストにつき複数のプレイヤーを信頼登録可能
- レッドストーンによる開閉操作はデフォルトで許可
- 町の役職（市長・副市長・補佐）は保護をバイパス可能（**この仕様の理由：いたずら目的で保護チェスト等を設置されることを防止するため**）

---

## ⚠️ 注意事項

<Callout type="warn">
**他の町の範囲内で保護チェストを設置した場合**、その町の市長・副市長・補佐に中身を閲覧・破壊される可能性があります。盗難・トラブル防止のため、自分の町、または信頼できる町の中で利用してください。
</Callout>
