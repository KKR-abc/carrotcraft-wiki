<Tab value="🧪 ポーション系">

<Callout type="info" title="エッセンスの入手方法">
  ポーションのクラフトには特殊素材「エッセンス」が必要です。エッセンスはクラフトでは作れず、以下の方法でのみ入手できます。

  **グロウスエッセンス** (光るグロウストーンダスト)
  - **動物を繁殖させると5%の確率でドロップ**
  - 牛・豚・羊・鶏など、繁殖可能な動物なら何でもOK
  - 小麦や種で繁殖 → 子どもが生まれた瞬間に確率判定

  **シュリンクエッセンス** (光るプリズマリンの欠片)
  - **大型スライムまたはマグマキューブを倒すと10%の確率でドロップ**
  - サイズ3以上(最大サイズ)のスライム/マグマキューブが対象
  - 小さく分裂した後のスライムからはドロップしません

  ドロップ時は発光アイテム + チャイム音で通知されます。
</Callout>

### 魔神スポンジ
右クリックした地点を中心に、**半径12ブロックの水を一度に吸い取る**。**32回使用可 / 25pt消費**

バニラのスポンジは距離7・最大65ブロックまでしか吸わないので、海底の拠点づくりでは何十個も置き直すことになります。これは**バニラの約110倍（最大約7,200ブロック）**を1回で片付けます。

水源・流水だけでなく、**水没ブロック（waterlogged）の水も抜けます**。階段やハーフブロックに入った水はそのままに、ブロック自体は残ります。

<Callout type="warn">
  - **設置はできません。** 右クリックで発動する道具です（置くとバニラのスポンジとして働いてしまうため）
  - **他人の土地の水は吸えません。** 自分が建築できる範囲だけが対象です
  - 連続使用には**3秒のクールダウン**があります
</Callout>

## 🔧 アイテム修復

使用回数があるアイテムは、**魔神インゴット**（通称「まじ！？インゴット」）で修復できます。

<Steps>
  <Step>**金床**を開く</Step>
  <Step>左スロットに修復したいアイテムを置く</Step>
  <Step>右スロットに**魔神インゴット**を置く</Step>
  <Step>結果スロットから修復済みアイテムを取り出す（経験値1レベル消費）</Step>
</Steps>

<Callout type="info">
  作業台でも修復できます。
</Callout>
