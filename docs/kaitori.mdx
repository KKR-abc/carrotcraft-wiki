<Callout type="info" title="買取ショップとは？">
  余ったアイテムを **サーバーが買い取ってくれる**、運営管理のお店です。`/kaitori` で開いて、売りたいアイテムをクリックするだけで **CC (キャロットコイン)** がその場で入ります。
</Callout>

## 🥕 かんたんに言うと

<Cards>
  <Card title="① /kaitori で開く" description="買取ショップのGUIが開きます。買い取ってもらえるアイテムが並んでいます。" />
  <Card title="② 売りたいアイテムをクリック" description="確認画面で個数を決めて『確定』。受け取るCCも先に表示されます。" />
  <Card title="③ CCがすぐ入る" description="売れた分だけCCが即入金されます。売った履歴はすべて記録されます。" />
</Cards>

<Callout type="warn" title="これは『売る』専用です">
  買取ショップは **プレイヤー → サーバー** の一方通行です。ここでアイテムを **買う (サーバーが販売する)** ことはできません。買い物は [CarrotMarket や QuickShop](/docs/economy) を使ってください。
</Callout>

***

## 🧰 使い方

<Steps>
  <Step>
    **`/kaitori` を開く**

    買取ショップの一覧が開きます。今サーバーが買い取っているアイテムだけが並びます。
  </Step>
  <Step>
    **売りたいアイテムをクリック**

    そのアイテムの **確認画面** が開きます。左右のクリックはどれでもOKです。
  </Step>
  <Step>
    **個数を決めて『確定』**

    ボタンで個数を増減し、受け取るCCを確認してから確定します。**間違えても確定するまでは売れません**。
  </Step>
</Steps>

### 個数の決め方（確認画面）

チャット入力は使いません。すべて **ボタンだけ** で操作します。

| ボタン | 動作 |
| --- | --- |
| `-64 / -10 / -1` | 個数を減らす |
| `+1 / +10 / +64` | 個数を増やす |
| **ぜんぶ** | 手持ち・本日の残り枠の範囲で最大まで |
| **確定** | その個数で売却（CC入金） |
| **キャンセル** | 一覧に戻る（売らない） |

### アイコンの見方

各アイテムのアイコンには、次の情報が表示されます。

| 表示 | 意味 |
| --- | --- |
| 単価 | 1個あたり何CCで買い取るか |
| 本日の残り枠 | 全体のこり ○個 / 自分のこり ○個 |
| 自分の本日売却数 | 今日ここで何個売ったか |
| **灰色のガラス板** | 本日の上限に達して売れない（明日また売れます） |

## 📋 買取のルール

| 項目 | 内容 |
| --- | --- |
| 買い取るもの | **素のアイテムのみ**（名前・エンチャント・カスタムの付いていない物） |
| 買い取らないもの | 名前付き・エンチャント付き・**圧縮品・魔神アイテム**などの特殊品 |
| 品目と価格 | **運営が設定**します。買取品目・単価・上限は随時調整されます |
| 1日の上限 | アイテムごとに **全体の上限** と **1人あたりの上限** があります |
| 上限のリセット | 毎日 **0:00（日本時間）** |
| 入金 | 売れた瞬間に **即時** CCが入ります |

<Callout type="info" title="スポナーなど『中身つき』の買取">
  スポナー（中のモンスターの種類で価値が全く違います）のような **中身つきアイテム** は、運営が登録した物と **中身まで完全に一致** したときだけ買い取られます。種類が違うスポナーは対象外です。
</Callout>

<Callout type="warn" title="特殊品は買い取りません（増殖防止）">
  名前・エンチャント・特殊データの付いたアイテムは、原則として買取の対象外です。これは価値の取り違えや増殖を防ぐための仕組みです。買い取ってほしい特殊品がある場合は運営に相談してください。
</Callout>

| コマンド | 説明 |

| /kaitori | 買取ショップを開く（別名: /buyshop, /sellshop） |

## ❓ よくある質問

<Accordions>
  <Accordion title="アイテムが灰色になっていて売れません">
    そのアイテムが **本日の上限**（全体または自分）に達しています。上限は毎日 **0:00（日本時間）** にリセットされるので、翌日また売れます。
  </Accordion>
  <Accordion title="持っているのに一覧に出てきません">
    そのアイテムは **今サーバーが買い取っていない** 品目です。買取品目は運営が設定していて、随時変わります。
  </Accordion>
  <Accordion title="圧縮品や魔神アイテムを売れますか？">
    売れません。名前・エンチャント・特殊データの付いたアイテムは、価値の取り違えや増殖を防ぐため買取の対象外です。
  </Accordion>
  <Accordion title="スポナーが売れません">
    買取ショップに登録された物と **中身のモンスターまで一致** している必要があります。種類の違うスポナーは対象外です。
  </Accordion>
  <Accordion title="売ったのにCCが入っていません">
    売却は成功した分だけ即時入金されます。入金に失敗した場合は **アイテムが返却** され、CCも減りません（売買が中途半端に終わることはありません）。それでもおかしいと感じたら運営に報告してください。
  </Accordion>
</Accordions>
