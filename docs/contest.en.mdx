<Callout type="warn" title="🏛️ The 2nd Building Contest is open">
  **Entries close on Sunday, September 13, 2026.** No set theme — anything you build on the main (Kokka) server can be entered.
</Callout>

## 📋 Entry requirements

| Item | Type | Details |
| --- | --- | --- |
| Deadline | spec | **Sunday, September 13, 2026** |
| Theme | spec | **Free build** (no set theme) |
| Where to build | spec | Must be built on the **main (Kokka) server** — it does **not** have to be inside a town |
| How to enter | spec | Post in the entry thread on Discord |

<Callout type="info" title="Building outside a town is fine">
  The old "must be inside your town" requirement is **gone**. Anywhere on the main server counts, inside a town or not.
</Callout>

| Place | Type | Prize |

## 🧰 How to enter

<Steps>
  <Step>
    **Build it on the main server**

    Any theme you like. Finish it before the deadline.
  </Step>
  <Step>
    **Post in the Discord entry thread**

    [Entry thread here](https://discord.com/channels/1476369911940124826/1529830800529424406) (Discord). Screenshots and the location of your build make judging easier.
  </Step>
  <Step>
    **Get your entry in before the deadline**

    Entries after Sunday, September 13 cannot be accepted.
  </Step>
</Steps>

</Callout>
