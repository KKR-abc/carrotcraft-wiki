<Callout type="info" title="🐔 ChickenBomber">
ボンバーとサバイバーに分かれて戦う非対称型 PVP ゲームです。サバイバーは逃げながら「**でんせつのたまご**」を集め、ボンバーは爆弾チキンでサバイバーの全滅を狙います。
</Callout>

## 📖 ゲームの流れ

### 1. 収集フェーズ（前半戦）

<Tabs items={['🥚 サバイバー', '💥 ボンバー']}>
<Tab value="🥚 サバイバー">

- **爆破と収集** — チキンボンバーの爆発を回避し、爆発跡に出現する「でんせつのたまご」を集めます
- **チェスト** — ステージに落ちているチェストから、でんせつのたまごやポーションを入手できます
- **回復** — たまごを**5個以上**持った状態でスニークを続けると、体力を回復できます
- **フェーズ移行** — サバイバー全員のたまご所持数が一定数を超えると「逆襲フェーズ」に切り替わります

</Tab>
<Tab value="💥 ボンバー">

- **爆弾の設置** — チキンボンバーを設置し、サバイバーを全滅させます
- **爆破範囲** — 爆発は**十字の範囲**にダメージを与えます
- **誘爆** — 爆発が他のチキンボンバーに当たると、通常より早く起爆（誘爆）します

</Tab>
</Tabs>

### 2. 逆襲フェーズ（後半戦）

<Tabs items={['🏹 サバイバー', '💥 ボンバー']}>
<Tab value="🏹 サバイバー">

- **復活** — 脱落していたサバイバーが**体力1**で復活します
- **反撃** — クロスボウを獲得します
- **狙撃** — クロスボウを持って**スニーク（2秒程度）**でたまごを装填し、ショットを放てます。弾道は**直線的**です

</Tab>
<Tab value="💥 ボンバー">

- **ダメージ** — ステージ内にテレポートし、サバイバーからのダメージを受けるようになります
- **補充** — チェストから追加のチキンボンバーを獲得し、最後まで全滅を狙います

</Tab>
</Tabs>

## 📋 重要なポイント

| 項目 | 対象 | 説明 |
|---|---|---|
| スタミナシステム | Movement | 走り続けるとスタミナが減り、移動速度が低下。歩くか止まることで回復 |
| たまごのドロップ | Survivor | サバイバーが脱落すると、所持していたたまごの半分をその場に落とす |
| 補充速度 | Bomber | サバイバーが集めたたまごの数に応じて、ボンバーの爆弾補充時間が変化 |
| 最大所持数 | Bomber | チキンボンバーは最大6個まで貯めることができる |

## 🥚 でんせつのたまご 入手条件

| 入手方法 | 種別 | 説明 |
|---|---|---|
| 爆発跡から拾う | pickup | チキンボンバーの爆発跡に出現するたまごを拾う |
| チェストから入手 | pickup | ステージに落ちているチェストを開ける |
| 脱落者のドロップ | pickup | 脱落したサバイバーが落とした半分のたまごを拾う |

## 🔧 ゲーム開始方法

<Steps>
<Step>
### 待機場所に集合
ロビーまたは待機エリアでゲーム参加者が集まります。
</Step>
<Step>
### ボンバー希望を選択
待機場所で「**ボンバーを希望するか**」を選択できます。
</Step>
<Step>
### 人数調整
人数調整のため、一部プレイヤーが**CPU**になることもあります。
</Step>
<Step>
### マッチ開始
収集フェーズからスタート。状況に応じて逆襲フェーズへ移行します。
</Step>
</Steps>
