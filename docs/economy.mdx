## 🏪 CarrotMarket（管理ショップ）

CarrotMarketはサーバー運営の自動変動ショップです。`/market` でアクセスできます。

### 価格の仕組み

```
価格 = 金庫 ÷ 在庫
```

- **売ると** → 金庫が減り、在庫が増える → **価格が下がる**
- **買うと** → 金庫が増え、在庫が減る → **価格が上がる**
- **毎日** → 金庫が少し回復する（お金が世界に入る）

たくさん売られているアイテムは安くなり、買われているアイテムは高くなります。市場の動きを読んで取引しましょう。

<Callout type="info" title="価格推移を確認する">
[CarrotMarket Web](https://market.carrotcraft.net/) でアイテムの価格推移をブラウザから確認できます。相場をチェックしてから取引するのがおすすめです。
</Callout>

### 便利機能

- 📊 **価格グラフ** — 最低 / 現在 / 最高 / トレンドの統計パネル付き。バーに価格が直接表示されます
- 📦 **スタックモード** — 1スタック単位（64〜4,096個）でまとめ売買。画面中央上のボタンで切替（モード中は画面が水色になります）
- 🔃 **並び替え** — アイテム一覧をソートできます

## ✨ マジンポイント

CarrotMarketでの取引で**マジンポイント**が貯まります。マジンポイントは特殊アイテム「**マジンインゴット**」（通称「まじ！？インゴット」）への変換や、**MajinCraftカスタムアイテム**の使用に必要です。

### ポイントの貯め方

CarrotMarketでアイテムを**売買するたびに**自動でポイントが付与されます。

| 取引数量 | 付与ポイント | 備考 |
|---------|------------|------|
| 1〜10個 | 1 pt | 1回の取引で1ポイント |
| 11〜20個 | 2 pt | 1回の取引で2ポイント |
| 64個 | 7 pt | 1回の取引で7ポイント |

<Callout type="info">
取引数の10%（切り上げ・最低1pt）が付与されます。
</Callout>

### ポイントの確認

- **`/market` のGUI** — 右下のアイコンで所持ポイントを確認可能
- **`/majin`** — コマンドでもポイント確認が可能

### マジンインゴットへの変換

| コマンド | 説明 |
|---------|------|
| `/majin` | ポイント確認 |
| `/majin convert [数量]` | ポイントをマジンインゴットに変換 |

- **100pt = マジンインゴット1個**
- マジンインゴットは[カスタムレシピ](/docs/custom-recipes)の素材に使用できます
- 金床で使用回数制アイテムの修復にも使えます（詳しくは[カスタムレシピ](/docs/custom-recipes#アイテム修復)参照）

### MajinCraftアイテムの使用コスト

</Callout>

| アイテム | 消費ポイント |

## 🥕 オークション

プレイヤー間でアイテムを競り売りできる、**イングリッシュ式オークション**です。レアアイテムや高額品は、ショップよりオークションが向いています。

### 出品する

<Steps>
<Step>
### オークションを開く

`/auction` を実行してオークションGUIを開きます。
</Step>
<Step>
### 出品設定

左下の「**出品する**」からアイテムと開始価格・出品時間を設定します。
</Step>
</Steps>

| 項目 | 内容 |
|---|---|
| 開始価格 | 5,000 cc 〜 |
| 出品料 | 開始価格の **10%**（出品した時点で徴収。落札されてもされなくても返金はありません） |
| 同時出品 | 3件まで（**クールタイムは廃止**しました） |
| 落札手数料 | 落札額の **5%** |

### 入札する

- 一覧からアイテムをクリックして詳細を確認 → **GUI** または `b <金額>` で入札
- 他の人に上回られたら、入札額は**即時全額返金**されます

### 受け取り

| コマンド | 説明 |
|---------|------|
| `/auction` | オークション一覧を開く |
| `/auction box` | 落札品・返金の受け取り（**保管期限7日間**） |
| `/auction notify off` | 通知をオフ |

## 🛒 QuickShop（プレイヤーショップ）

QuickShop-Hikariを使って、自分のショップを開くことができます。**取引手数料はかかりません。**

<Callout type="warn" title="ショップは町のショップエリア限定">
ショップを作成できるのは `/plot set shop` でショップエリアに設定された町の土地のみです。詳しくは [QuickShop ガイド](/docs/quickshop) を参照してください。
</Callout>

<Steps>
<Step>
### チェストを設置

ショップにしたい場所にチェストを設置します。
</Step>
<Step>
### ショップを作成

チェストを左クリックして `/qs create <価格>` を実行します。
</Step>
<Step>
### 完成

ショップが作成され、自動で売買が始まります。
</Step>
</Steps>

CarrotMarketで扱わない加工品やレアアイテムはQuickShopで取引しましょう。詳しい使い方は [QuickShop ガイド](/docs/quickshop) を参照してください。

### QuickShopコマンド

| コマンド | 説明 |
|---------|------|
| `/qs create <価格>` | ショップ作成 |
| `/qs find <アイテム名>` | アイテムを販売しているショップを検索 |
