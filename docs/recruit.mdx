# 一緒に CarrotCraft を作りませんか？

CarrotCraft では、サーバーの運営を手伝ってくれる方を募集しています。

建築、イラスト、モデリング、動画制作、プラグイン開発、プレイヤー対応。やることは役職によって違いますが、どれもサーバーを動かすために必要な仕事です。

現在、**7つの役職**で募集しています。

<Callout type="info">
**複数の役職に応募できます。** フォームで複数選んだうえで、最も力を入れたいものを1つ選んでください。「スタッフをやりたいが建築も得意」といった応募も歓迎します。
</Callout>

## 応募条件

- CarrotCraft を **1週間以上プレイ**していること
- 日本語で問題なくコミュニケーションが取れること
- 責任感を持って行動できること
- **スタッフのみ Java版限定**です。他の役職は統合版でも構いません

<Callout type="warn" title="ボランティアでの活動です">
報酬・給与などの金銭は一切発生しません。ご了承のうえでご応募ください。
</Callout>

<Callout type="warn" title="制作物の扱いについて">
運営として制作したもの（動画・建築・イラスト・モデル・資料など）は、**CarrotCraft の制作物として扱わせていただきます**。サーバーの宣伝・広報・配信・Wiki など、サーバーに関わる用途で自由に使用します。

ご自身のポートフォリオに「CarrotCraft で制作したもの」として掲載することは自由です。
</Callout>

## 役職ごとの詳細

<Accordions>
<Accordion title="プロジェクトリーダー">
企画を立て、実行までを管理する役職です。メンバーに役割を振り、進行を追いかけます。

**求めること**

- 人をまとめた経験（Minecraft 内外を問いません）
- 締め切りを決めて進行を管理できること
- Discord の運用、資料作成ができる方は歓迎します

**フォームで聞くこと**: これまでの経験 / 進めたい企画 / 使えるツール
</Accordion>

<Accordion title="開発者">
プラグイン、Discord Bot、Web サイト、サーバー構築など、サーバーの仕組みを作る役職です。

**求めること**

- Minecraft プラグインの開発（Java / Paper・Folia）
- または Discord Bot、Web、インフラ、データベースなどの開発経験
- 既存のコードを読んで修正できる方も歓迎します

Minecraft のプラグインが未経験でも、他の開発経験があれば応募できます。

**フォームで聞くこと**: できること / 使える言語 / GitHub などの制作物
</Accordion>

<Accordion title="動画作成">
サーバーの宣伝用ショート動画（縦型・15〜60秒程度）を制作する役職です。

実際の投稿は [YouTube チャンネル](https://www.youtube.com/@CarrotCraft7) をご覧ください。

<Callout type="info">
**選考課題があります。** 応募時に、宣伝ショートを1本制作して提出していただきます。限定公開やドライブのリンクでも構いません。
</Callout>

**フォームで聞くこと**: できること（撮影・編集・サムネイル・台本・実況）/ 使用ソフト / 課題の提出
</Accordion>

<Accordion title="スタッフ（Java版限定）">
プレイヤーからの問い合わせ対応、チャットの見回り、トラブル対応を行う役職です。

**求めること**

- プレイヤーの相談に親身に対応できること
- ルールに沿った公平な判断ができること
- Discord を毎日確認できること

**フォームで聞くこと**: スタッフ経験 / 荒らしや揉め事への対応方針 / 得意な業務
</Accordion>

<Accordion title="ビルダー">
サーバー内の建築物や地形を制作する役職です。

**求めること**

- 城・町・テーマパークなどの制作経験
- WorldEdit を使える方は歓迎します
- 他の人の建築に合わせて拡張できる方も歓迎します

**フォームで聞くこと**: 作品の画像URL（3点以上あると判断しやすいです）/ 得意なジャンル / WorldEdit の習熟度
</Accordion>

<Accordion title="絵師">
ロゴ、アイコン、キャラクターなどのイラストを制作する役職です。

**求めること**

- キャラクター、ロゴ・バナー、アイコン、背景、ドット絵などの制作
- 使用ソフトは問いません

**フォームで聞くこと**: 作品URL（pixiv・X・ポートフォリオサイトなど）/ 描けるもの / 使用ソフト
</Accordion>

<Accordion title="モデラー">
アイテム、家具、モブなどの3Dモデルを制作する役職です。

**求めること**

- Blockbench、Blender などでのモデリング
- テクスチャやアニメーションの制作も歓迎します

**フォームで聞くこと**: 作品URL / 作れるもの / 使用ソフト
</Accordion>
</Accordions>

## よくある質問

<Accordions>
<Accordion title="複数の役職に応募できますか">
できます。フォームで複数選んだうえで、最も力を入れたい役職を1つ選んでください。その役職の質問が表示されます。他に選んだ役職については、最後の自由記述欄にまとめて記入できます。
</Accordion>

<Accordion title="経験がなくても応募できますか">
役職によります。スタッフと開発者は未経験の方も応募できます。

ビルダー・絵師・モデラー・動画作成については、作品を提出していただく形になります。少なくとも1点はご用意ください。完成度だけでなく、制作の意図も見ています。
</Accordion>

<Accordion title="統合版でも応募できますか">
スタッフのみ Java版限定です。それ以外の役職は統合版でも構いません。
</Accordion>

<Accordion title="学生でも応募できますか">
できます。年齢欄は「中学生」「高校生」といった記入で構いません。無理のない範囲で活動できることを重視しています。
</Accordion>

<Accordion title="結果はいつ分かりますか">
内容を確認のうえ、Discord からご連絡します。応募が多い場合はお時間をいただくことがあります。
</Accordion>
</Accordions>
