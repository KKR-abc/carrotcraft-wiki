<Callout type="info" title="QuickShop-Hikari とは">
チェストを使って自分のショップを開けるプラグインです。アイテムの売買を自動で行い、オフライン中も取引が続きます。**取引手数料はかかりません。**
</Callout>

<Callout type="warn" title="ショップは町のショップエリア限定">
ショップを作成できるのは、**ショップエリアに設定された町の土地**だけです。土地の上で `/plot set shop` を実行してから作成してください（街の外にはショップを作れません）。
</Callout>

## 🏪 ショップの作り方

<Steps>
<Step>
### チェストを設置

ショップにしたい場所にチェスト（またはバレル・シュルカーボックス）を設置します。看板を置くスペースが隣に必要です。
</Step>
<Step>
### 売りたいアイテムを持つ

売りたいアイテムを手に持ちます。持っている**数量がまとめ売りの単位**になります（例: ダイヤ16個を持って作成 → 16個単位で取引）。
</Step>
<Step>
### チェストを左クリック

アイテムを持ったままチェストを左クリックします。
</Step>
<Step>
### 価格を入力

チャットに価格を聞かれるので、数字を入力してEnterを押します。

ショップ完成！チェストの横に看板が自動設置され、上にアイテムが浮かびます。
</Step>
</Steps>

## 🔀 ショップの種類

<Tabs items={['販売ショップ (Selling)', '買取ショップ (Buying)']}>
<Tab value="販売ショップ (Selling)">

**あなたがアイテムを売る**（デフォルト）。チェストにアイテムを入れておくと、プレイヤーが購入できます。

```
/qs sell    ← 販売モードに切り替え
```

</Tab>
<Tab value="買取ショップ (Buying)">

**あなたがアイテムを買い取る**。あなたのアカウントにお金があれば、プレイヤーがアイテムを売りに来ます。

```
/qs buy     ← 買取モードに切り替え
```

</Tab>
</Tabs>

<Callout type="info" title="売買両方したい場合">
ラージチェストを置いて、片側を販売、もう片側を買取にすると両方のショップを作れます。
</Callout>

## 📜 コマンド一覧

### ショップ管理

| コマンド | 説明 |
|---------|------|
| `/qs create <価格>` | コマンドでショップ作成 |
| `/qs price <価格>` | 価格を変更 |
| `/qs buy` | 買取モードに切り替え |
| `/qs sell` | 販売モードに切り替え |
| `/qs item` | 取扱アイテムを変更 |
| `/qs size` | まとめ売り数量を変更 |
| `/qs name <名前>` | ショップにカスタム名を設定 |

### ショップ検索

```
/qs find <アイテム名>
```

指定したアイテムを扱っている最寄りのショップを検索します。部分一致で検索可能（例: `/qs find dia` でダイヤ関連のショップを検索）。

### スタッフ管理

| コマンド | 説明 |
|---------|------|
| `/qs staff add <プレイヤー>` | スタッフを追加（在庫管理を委任） |
| `/qs staff del <プレイヤー>` | スタッフを削除 |
| `/qs staff list` | スタッフ一覧 |

<Callout type="info">
スタッフはチェストの在庫管理ができますが、ショップ設定の変更はできません。
</Callout>

### 所有権

| コマンド | 説明 |
|---------|------|
| `/qs setowner <プレイヤー>` | オーナーを変更 |
| `/qs transfer <プレイヤー>` | 全ショップを移管 |

<Callout type="info" title="土地の権限者はショップを撤去できます">
ショップが建っている**土地の権限を持つプレイヤー**は、そのショップを破壊できます。他人の土地に置いたショップは撤去される可能性があるため、自分の土地（または許可を得た場所）に設置しましょう。
</Callout>

## 📦 在庫管理

<Tabs items={['販売ショップ', '買取ショップ']}>
<Tab value="販売ショップ">

チェストにアイテムを入れておきます。プレイヤーが購入するとアイテムが減り、お金があなたのアカウントに入ります。チェストが空になると購入できなくなります。

</Tab>
<Tab value="買取ショップ">

あなたのアカウントにお金があれば、プレイヤーがアイテムを売りに来ます。アイテムはチェストに入ります。チェストが一杯になると買取できなくなります。

</Tab>
</Tabs>

## 🔔 取引の通知

誰かがあなたのショップで取引すると、次回ログイン時にチャットで通知されます。手動で取得する場合:

```
/qs fetchmessage
```
