## ⚙️ 基本コマンド

| コマンド | 説明 |
|---------|------|
| `/rtp` | ランダムテレポート |
| `/rule` | サーバールール表示（`/rule 1`〜`/rule 8` で章ごとに読める） |
| `/gui toggledeath` | 死亡時のGUI本自動付与をON/OFF |

## 🏠 ホームコマンド

| コマンド | 説明 |
|---------|------|
| `/home` | ホームGUIを開く（ホームの一覧・テレポート・設定・削除がすべてGUIで操作可能） |

## 💰 経済コマンド

| コマンド | 説明 |
|---------|------|
| `/bal` | 所持金確認 |
| `/pay <プレイヤー> <金額>` | 送金 |
| `/baltop` | 資産ランキング |
| `/market` | CarrotMarketを開く |
| `/qs create <価格>` | QuickShopを作成 |
| `/qs find <アイテム名>` | ショップ検索 |
| `/auction` | オークションを開く（出品もここから） |
| `/auction box` | 落札品・返金の受け取り（保管7日間） |
| `/auction notify off` | オークション通知をオフ |

## ⚔️ PvPコマンド

| コマンド | 説明 |
|---------|------|
| `/pvp` | PvPのON/OFFを切り替え |
| `/pvp mode <モード>` | 戦闘モードを選択（下表参照） |

| モード | 許可される攻撃 |
|---|---|
| `crystal` | 爆発系 ＋ 剣・斧 ＋ 弓 |
| `mace` | メイス ＋ ウィンドチャージ ＋ 斧 ＋ 弓 |
| `sword` | 剣・斧の近接のみ |
| `potion` | 剣・斧 ＋ スプラッシュポーション |
| `all` | 全部あり（デフォルト） |

<Callout type="info">
ダメージが通るのは**お互いのモードが両方許可している攻撃のみ**です（例: crystal同士は爆発OK、crystal vs sword は剣・斧のみ）。戦闘中はモード変更不可（15秒クールダウン）。現在のモードはアクションバーに表示されます。
</Callout>
