## ⚙ 基本・便利コマンド

| コマンド | 説明 |
|---------|------|
| `/rtp` | ランダムテレポート |
| `/rule` | サーバールール表示（`/rule 1`〜`/rule 8` で章ごとに読める） |
| `/gui toggledeath` | 死亡時のGUI本自動付与をON/OFF |
| `/gui give` | GUI本の取得 |
| `/nv` | 常時暗視 |
| `/skills` | スキルメニューを開く [詳細](/docs/skills) |
| `/assyuku` | 圧縮メニューを開く  [詳細](/docs/artisan) |
| `/ai` | AIにわからないことを質問 |
| `/accept` | 承認 |
| `/deny` | 招待などを拒否する |
| `/afk` | AFKモードになる |
| `/back` | 死亡地点にもどる（初心者期間のみ） |
| `/lock` | チェストなどを保護する [詳細](/docs/bolt) |
| `/tablist` | タブをチャットに表示する |
| `/p <プレイヤー>` | 住民の情報を見る（Towny `/resident` の別名） |
| `/settings` | 各種設定を開く（`/setting` でも可） |

| コマンド | 説明 |

## ⚔ PvPコマンド

| コマンド | 説明 |
|---------|------|
| `/pvp` | PvPのON/OFFを切り替え |
| `/pvp mode <モード>` | 戦闘モードを選択（下表参照） |

| モード | 許可される攻撃 |
|---|---|
| `crystal` | 爆発系 ＋ 剣・斧 ＋ 弓 |
| `mace` | メイス ＋ ウィンドチャージ ＋ 斧 ＋ 弓 |
| `sword` | 剣・斧の近接のみ |
| `potion` | 剣・斧 ＋ スプラッシュポーション |
| `all` | 全部あり（デフォルト） |

<Callout type="info">
ダメージが通るのは**お互いのモードが両方許可している攻撃のみ**です（例: crystal同士は爆発OK、crystal vs sword は剣・斧のみ）。戦闘中はモード変更不可（15秒クールダウン）。現在のモードはアクションバーに表示されます。
</Callout>
