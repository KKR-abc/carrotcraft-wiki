<Callout type="info" title="Towny とは">
土地保護と町づくりのプラグインです。町を作り、住民を招待し、土地を守りながら自分たちの街を発展させましょう。国家を建設して複数の町を束ねることもできます。
</Callout>

<Callout type="warn" title="町には毎日 500 CC の維持費がかかります">
町銀行から自動で引き落とされ、残高不足で支払えない場合は町が削除されます。定期的に `/t deposit` で入金しておきましょう。
</Callout>

## 🏰 町の作り方

<Steps>
<Step>
### 町を作成する

```
/t new <町の名前>
```

- 費用: **4,000 CC**
- 町名は**英数字のみ**使用可能（日本語不可）
- 作成すると、立っている場所がホームブロック（町の中心）になります
</Step>
<Step>
### 町への参加

```
/t join <町名>
```

オープンな町であればコマンドで参加できます。オープンでない町は、町長からの招待が必要です。
</Step>
</Steps>

## 📊 町のレベル

住民数に応じて町のランクが上がり、確保できる土地の上限が増えます。

| 住民数 | 称号 | 町長の肩書き | 最大チャンク |
|--------|------|------------|-------------|
| 1人 | 開拓地 | 開拓者 | 16 |
| 2人 | 集落 | 長 | 32 |
| 6人 | 村 | 村長 | 96 |
| 10人 | 町 | 町長 | 160 |
| 14人 | 大きな町 | 市長 | 224 |
| 20人 | 都市 | 都市長 | 320 |
| 24人 | 大都市 | 首長 | 384 |
| 28人 | メトロポリス | 首領 | 448 |

最大チャンク数は `住民数 × 12` でも計算されます（レベル上限とどちらか大きい方が適用）。

<Callout type="warn">
アウトポスト（飛び地の土地確保）は無効です。町の土地は連続して確保する必要があります。
</Callout>

## 🗺️ 土地の管理

### 土地の確保（Claim）

```
/t claim
```

今いるチャンク（16×16ブロック）を町の土地にします。

- 費用: 1チャンクあたり **500 CC**
- 既存の町の土地に隣接している必要があります
- 他の町から **5チャンク以上** 離れている必要があります
- プレイヤー1人あたり最大 **100プロット** まで所有可能
- `/t claim auto` で移動しながら連続確保も可能

| コマンド | 説明 |
|---------|------|
| `/t claim` | 今いるチャンクを確保 |
| `/t claim auto` | 資金が続く限り自動で確保 |
| `/t claim <半径>` | 自分を中心に指定半径のチャンクをまとめて確保 |
| `/t claim fill` | 町の土地に囲まれた穴を埋める |

### 土地の放棄

| コマンド | 説明 |
|---------|------|
| `/t unclaim` | 今いるチャンクを放棄 |
| `/t unclaim <半径>` | 指定半径をまとめて放棄 |
| `/t unclaim all` | 町の土地をすべて放棄（ホームブロックは残る） |
| `/t cede plot <町名>` | 今いるチャンクを他の町に譲渡 |

### プロットの売買

| コマンド | 説明 |
|---------|------|
| `/plot forsale <価格>` | 土地を売りに出す（`/plot fs` でも可） |
| `/plot forsale circle <半径> <価格>` | 円形の範囲をまとめて売りに出す |
| `/plot forsale rect <半径> <価格>` | 四角形の範囲をまとめて売りに出す |
| `/plot notforsale` | 売却中止（`/plot nfs` でも可） |
| `/plot claim` | 売りに出ている土地を購入 |
| `/plot claim auto` | 近くの売り出し中プロットを自動購入 |
| `/plot unclaim` | 所有しているプロットを返却 |
| `/plot unclaim circle <半径>` | 円形の範囲をまとめて返却 |
| `/plot unclaim rect <半径>` | 四角形の範囲をまとめて返却 |
| `/plot evict` | 町長がプロットの所有者を解除 |
| `/plot evict forsale` | 所有者を解除して即座に売りに出す |

### 町ごと売買する

| コマンド | 説明 |
|---------|------|
| `/t forsale <価格>` | 町ごと売りに出す（町長） |
| `/t notforsale` | 町の売却を中止 |
| `/t buytown <町名>` | 売りに出ている町を購入 |
| `/t merge <町名>` | 指定した町を自分の町に併合する（相手町長の承諾が必要） |

## 👥 住民の管理

| コマンド | 説明 |
|---------|------|
| `/t invite <プレイヤー名>` | 住民を招待 |
| `/t invite sent` | 自分の町が送った招待の一覧 |
| `/t invite removeall` | 送った招待をすべて取り消す |
| `/t add <プレイヤー名>` | 住民を直接追加（相手の承諾が必要） |
| `/t kick <プレイヤー名>` | 住民を追放 |
| `/t leave` | 町から脱退 |
| `/t reslist <町名>` | 住民一覧 |
| `/t online` | オンラインの町メンバー |
| `/t purge <日数>` | 指定日数ログインしていない住民を一括追放 |
| `/t say <メッセージ>` | 町のオンラインメンバー全員にメッセージを送る |

### 招待を受けた側の操作

町から招待されたときは、以下のコマンドで応答します。

| コマンド | 説明 |
|---------|------|
| `/invite list` | 自分が受け取っている招待の一覧 |
| `/invite accept <町名>` | 招待を承諾して町に加入 |
| `/invite deny <町名>` | 招待を断る |
| `/invite deny all` | すべての招待を断る |

### 信頼プレイヤー・信頼町

| コマンド | 説明 |
|---------|------|
| `/t trust add <プレイヤー>` | 町全体で信頼するプレイヤーを追加 |
| `/t trust remove <プレイヤー>` | 信頼を解除 |
| `/t trust list` | 信頼プレイヤーの一覧 |
| `/t trusttown add <町名>` | 町ぐるみで信頼する町を追加 |
| `/t trusttown remove <町名>` | 信頼町を解除 |
| `/t trusttown list` | 信頼町の一覧 |

### 牢屋

牢屋プロット（`/plot set jail`）がある町では、住民を投獄できます。

| コマンド | 説明 |
|---------|------|
| `/t jail <プレイヤー>` | 住民を投獄（既定1時間） |
| `/t jail <プレイヤー> <時間>` | 時間を指定して投獄（**最大5時間**） |
| `/t unjail <プレイヤー>` | 釈放する |

<Callout type="info">
保釈金による自主脱出は無効です。釈放は町長・警備ランクの操作か、時間経過を待つ必要があります。
</Callout>


## 🔐 権限設定

### 町全体の権限

```
/t set perm <グループ> <アクション> <on/off>
```

**グループ:** `resident`（住民）, `nation`（国家メンバー）, `ally`（同盟）, `outsider`（部外者）

**アクション:** `build`（建築）, `destroy`（破壊）, `switch`（コンテナ・スイッチ操作）, `itemuse`（アイテム使用）

例:

```
/t set perm resident build on     ← 住民に建築を許可
/t set perm outsider switch off   ← 部外者のコンテナ操作を禁止
```

### プロット単位の権限

```
/plot set perm <グループ> <アクション> <on/off>
```

### 信頼プレイヤー

```
/plot trust add <プレイヤー>      ← プロットへの信頼追加
/plot trust remove <プレイヤー>
/t trust add <プレイヤー>         ← 町全体への信頼追加
/t trust remove <プレイヤー>
```

## 🏗️ プロットタイプ

プロットには種類を設定でき、それぞれ異なる挙動を持ちます。

```
/plot set <タイプ>
```

| タイプ | 説明 |
|--------|------|
| `default` | 通常のプロット |
| `shop` | ショップ用プロット |
| `arena` | PvPアリーナ（フレンドリーファイア有効） |
| `embassy` | 大使館（町外のプレイヤーが購入可能） |
| `wilds` | 荒野タイプ（特定ブロックのみ採掘可能） |
| `inn` | 宿屋（ベッドスポーン設定可能） |
| `jail` | 牢屋 |
| `farm` | 農場（農作物関連ブロックのみ操作可能） |
| `bank` | 銀行 |

`/plot set reset` で通常のプロットに戻せます。

### プロットのその他の設定

| コマンド | 説明 |
|---------|------|
| `/plot set name <名前>` | プロットに名前を付ける |
| `/plot set minjoindays <日数>` | 町への加入から一定日数が経った住民のみ購入可に（`clear` で解除） |
| `/plot set maxjoindays <日数>` | 加入から一定日数以内の住民のみ購入可に（`clear` で解除） |
| `/plot clear` | プロット内の特定ブロックを一括撤去 |
| `/plot jailcell add` | 牢屋プロットに独房を追加 |
| `/plot jailcell remove` | 独房を削除 |

### プロット単位のトグル

町全体の設定より優先されます。

| コマンド | 説明 |
|---------|------|
| `/plot toggle pvp` | このプロットのPvP |
| `/plot toggle fire` | このプロットの延焼 |
| `/plot toggle explosion` | このプロットの爆発 |
| `/plot toggle mob` | このプロットのモブスポーン |
| `/plot toggle taxed` | このプロットへの課税 |

### 権限の確認と一括設定

| コマンド | 説明 |
|---------|------|
| `/plot perm` | 今いるプロットの権限を表示 |
| `/plot perm gui` | **権限をGUIで設定**（コマンドを覚えなくて済みます） |
| `/plot perm hud` | プロット情報をスコアボードに常時表示 |
| `/plot perm add <プレイヤー>` | 特定プレイヤーだけに権限を与える |
| `/plot perm remove <プレイヤー>` | 個別権限を削除 |
| `/plot set perm reset` | 権限を既定値に戻す |

<Callout type="info" title="GUIが一番早い">
権限設定は `/plot perm gui` を使うのが確実です。クリックだけで建築・破壊・スイッチ・アイテム使用を、住民／同盟／部外者ごとに切り替えられます。
</Callout>

## 📦 プロットグループと地区

複数のプロットをまとめて扱う機能です。**大きな建物や区画をまとめて売買・設定したいとき**に使います。

### プロットグループ（まとめて売買・設定）

<Steps>
<Step>
### グループを作る

```
/plot group new <グループ名>
```

今いるプロットが新しいグループの最初のメンバーになります。
</Step>
<Step>
### プロットを追加する

`/res toggle plotgroup` をONにしてから土地を確保すると、自動でグループに追加されます。手動なら各プロットで `/plot group add <グループ名>` を実行します。
</Step>
<Step>
### まとめて操作する

```
/plot group forsale <価格>
/plot group set <タイプ>
```

グループ全体が1つの単位として売買・設定されます。
</Step>
</Steps>

| コマンド | 説明 |
|---------|------|
| `/plot group new <名前>` | グループを作成 |
| `/plot group add <名前>` | 今いるプロットをグループに追加 |
| `/plot group remove` | 今いるプロットをグループから外す |
| `/plot group rename <新しい名前>` | グループ名を変更 |
| `/plot group delete` | グループを削除 |
| `/plot group set <タイプ>` | グループ全体のプロットタイプを設定 |
| `/plot group set perm ...` | グループ全体の権限を設定 |
| `/plot group toggle ...` | グループ全体のトグル設定 |
| `/plot group forsale <価格>` | グループごと売りに出す |
| `/plot group notforsale` | グループの売却を中止 |
| `/plot group trust add <プレイヤー>` | グループ全体に信頼プレイヤーを追加 |
| `/plot group trust remove <プレイヤー>` | 信頼を解除 |
| `/plot group perm gui` | グループの権限をGUIで設定 |

### 地区（District）

町の中を「商業区」「住宅区」のように区分けして管理するための機能です。売買はできず、**整理・表示のための区分**です。

| コマンド | 説明 |
|---------|------|
| `/plot district new <名前>` | 地区を作成 |
| `/plot district add <名前>` | 今いるプロットを地区に追加 |

## ❓ よくある質問

<Accordions>
<Accordion title="町が削除されるのはどんな時？">
町銀行の残高が不足して維持費（500 CC/日）を払えない場合に削除されます。定期的に `/t deposit` で入金しておきましょう。
</Accordion>
<Accordion title="他の人が自分の町の土地を壊せる？">
権限設定（`/t set perm`）で制御できます。デフォルトでは住民のみが建築・破壊可能で、部外者は操作できません。
</Accordion>
<Accordion title="町の最大チャンク数を増やすには？">
住民を増やすか、`/t buy bonus <数>` でボーナスチャンクを購入（1チャンク25 CC）してください。国家に参加するとボーナスチャンクも得られます。
</Accordion>
<Accordion title="MajinCraftアイテムとTowny権限">
MajinCraftのカスタムアイテム（ヴェインピッケル、ティンバーアックス、ブラストアロー等）は**Towny権限に従います**。建築権限がない場所ではブロックの破壊・爆発が発動しません。モブ操作系のアイテム（ポーション、レインボーシアー等）もモブ操作権限に準拠します。自分の町の土地か荒野でのみ使用できます。
</Accordion>
</Accordions>
