  CarrotCraft features unique crafting recipes that are not available in vanilla Minecraft. Use the `/recipes` command in-game to view the full list.

<Callout type="info" title="How to Obtain Essences">
  Potions require special "Essence" materials that cannot be crafted — they can only be obtained through gameplay.

  **Growth Essence** (glowing Glowstone Dust)
  - **5% drop chance when you breed animals**
  - Works with any breedable animal: cows, pigs, sheep, chickens, etc.
  - Breed with wheat/seeds → chance triggers when the baby spawns

  **Shrink Essence** (glowing Prismarine Shard)
  - **10% drop chance from killing large Slimes or Magma Cubes**
  - Only size 3+ (the largest size) counts
  - Smaller split slimes do NOT drop essences

  Drops as a glowing item with a chime notification.
</Callout>

### Majin Sponge
Right-click to **soak up every water block within a 12-block radius at once**. **32 uses / 25pt per use**

A vanilla sponge only reaches distance 7 and clears at most 65 blocks, so building an underwater base means placing them over and over. This clears **about 110x that (up to ~7,200 blocks)** in a single use.

It removes flowing water and source blocks, and also **drains waterlogged blocks** — the stairs or slabs themselves stay, only the water inside is removed.

<Callout type="warn">
  - **It cannot be placed.** It is a right-click tool (placing it would make it behave as a vanilla sponge)
  - **It will not touch water on other players' land.** Only areas where you can build are affected
  - There is a **3 second cooldown** between uses
</Callout>

## 🔧 Item Repair

Items with a use count can be repaired with a **Majin Ingot**.

<Steps>
  <Step>Open an **anvil**</Step>
  <Step>Place the item to repair in the left slot</Step>
  <Step>Place a **Majin Ingot** in the right slot</Step>
  <Step>Take the repaired item from the result slot (costs 1 XP level)</Step>
</Steps>

<Callout type="info">
  One Majin Ingot restores **16 uses**. Only the needed amount is consumed; extras are returned.
</Callout>

| Target Item | Restored Uses |
|-------------|---------------|
| Vein Pickaxe | 64 |
| Timber Axe | 64 |
| Gravity Rod | 64 |
| Warp Trident | 64 |
| Rainbow Shears | 16 |
| Ender Breath | 16 |
| Chicken Race | 16 |
| Leaf Shears | 64 |

## ⚠️ Important Notes

<Callout type="warn">
  - MajinCraft items **cannot be used** in furnaces, enchanting tables, grindstones, or smithing tables
  - The anvil only accepts the "repairable item + Majin Ingot" combination
  - Items will not activate in areas where you lack Towny permissions
  - Items will not activate if you don't have enough Majin Points
</Callout>
