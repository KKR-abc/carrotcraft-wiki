<Callout type="info" title="釣りを楽しもう">
水辺で釣った魚には、**レア度**と**サイズ**があります。珍しい魚や大きな魚ほど高値になりやすく、図鑑集めにも役立ちます。

必要なのは普通の釣り竿だけです。釣った魚は、その場で売る・図鑑へ記録する・大物を記念に保管する、という3通りの楽しみ方ができます。
</Callout>

## 🐟 はじめかた

<Steps>
<Step>
### 水面へ釣り竿を投げる

いつもの釣り竿を持って、水面へ右クリック。ウキが水に浮いていることを確認しよう。

</Step>
<Step>
### ウキが沈んだらすぐ巻き上げる

泡が近づき、ウキが沈んだ瞬間に右クリック。タイミングを逃すと釣果は手に入りません。

</Step>
<Step>
### 魚の名前・レア度・サイズを見る

インベントリの魚に表示される情報を確認しよう。大きい魚や珍しい魚は、売る前に保管するのもおすすめです。

</Step>
<Step>
### 売るか、残すかを決める

お金にするなら `/emf shop`、集めるならチェストへ。図鑑が有効な場合は、釣り上げた時点で自動的に記録されます。

</Step>
</Steps>

## ✨ レア度とサイズ

| レア度 | 特徴 |
|---|---|
| ジャンク | 魚ではないハズレ品。サイズや売値がないことがあります |
| コモン | 最も釣れやすい基本の魚 |
| レア | 少し珍しい。大きめの魚も増える |
| エピック | なかなか釣れない大物 |
| レジェンダリー | とても珍しい特別な魚 |

同じ種類の魚でもサイズが異なります。**大きいほど売値が高くなりやすい**ので、レア度だけでなくサイズも見比べてみよう。

<Callout type="tip" title="大物は売る前に確認">
レア度が高くても、同じ種類ならサイズによって価値が変わります。自己ベストになりそうな魚は、売る前に名前・サイズ・レア度を確認しておこう。
</Callout>

## 🗺️ 魚を探す

魚によっては、釣れる条件が決まっています。いつも同じ場所だけで釣るより、環境を変えると図鑑を埋めやすくなります。

| 条件 | 探し方 |
|---|---|
| バイオーム | 海、川、沼地、雪原、ジャングルなど、違う水辺を試す |
| 天気 | 晴れだけでなく、雨の日にも釣ってみる |
| 時間 | 昼と夜の両方で試す |
| ワールド | 通常世界以外で釣れる魚や、特殊な釣りが有効な場合があります |

魚ごとの正確な条件はゲーム内の図鑑やイベント案内を確認してください。未発見が残ったら、場所・天気・時間を一つずつ変えるのがコツです。

## ♻️ 漁場の回復

同じ場所で釣り続けると、その漁場の魚が一時的にいなくなります。魚がいなくなったら、少し離れた水辺へ移動するか、回復するまで待ちましょう。

現在の標準設定は次のとおりです。

| 項目 | 内容 |
|---|---|
| 漁場の範囲 | 最初に釣ったウキを中心とした半径8ブロック |
| 枯渇まで | 範囲内で合計20匹 |
| 回復時間 | 5分 |
| 集計 | 同じ漁場で釣る全プレイヤーの合計 |

20匹目は通常どおり釣れ、その時点で漁場が枯渇します。21匹目以降は食いついた時点で中断され、釣果・大会・ランキングにはカウントされません。5分経過すると再び釣れるようになります。途中まで釣った漁場も、5分間釣られなければ数がリセットされます。

<Callout type="info" title="釣れなくなったらウキの場所を移動">
判定されるのはプレイヤーの立ち位置ではなく、**ウキが落ちた場所**です。同じ場所に立ったままでも、ウキを8ブロック以上離れた場所へ投げれば別の漁場として釣れます。
</Callout>

<Callout type="tip" title="釣りを速くするコツ">
<CloudRain size={18} /> 雨が降る屋外の水面では、アタリが少し早くなります。釣り竿に**ルアーIII**が付いていると、さらに待ち時間を短縮できます。
</Callout>

## 💰 魚を売る

```text
/emf shop
```

<Steps>
<Step>
### 売却画面を開く

`/emf shop`を入力します。

</Step>
<Step>
### 売りたい魚を入れる

画面上部の空きスロットへ、EvenMoreFishで釣った魚を移動します。

</Step>
<Step>
### 金インゴットを左クリック

売却内容を確認して確定します。右クリックまたは画面を閉じるとキャンセルできます。

</Step>
</Steps>

持ち物にある対象魚を全部まとめて売る場合は、次のコマンドを使います。

```text
/emf sellall
```

ショップ内の「Sell All」からも、インベントリ内の対象魚をまとめて売却できます。

<Callout type="warn" title="売却前に確認">
売った魚は戻りません。レジェンダリーや思い出の大物、図鑑用に残したい魚はチェストへ保管しよう。
</Callout>

## 📖 魚図鑑

```text
/emf journal
```

魚図鑑では、釣ったことのある魚をレア度ごとに確認できます。魚を釣り上げた時点で記録されるため、**記録後に魚を売っても発見状況は消えません**。

図鑑の魚へカーソルを合わせると、魚ごとに次の記録を確認できます。

- 釣った回数
- 自分が釣った最大・最小サイズ
- 初めて釣った日
- サーバー全体の釣果や最大・最小サイズ

未発見の魚は隠された表示になります。まずレア度を選び、その中の未発見枠を埋めていこう。

<Tabs items={['図鑑を埋めたい', 'お金を稼ぎたい']}>
<Tab value="図鑑を埋めたい">

- まだ釣っていないレア度を確認する
- バイオーム・天気・時間を変えて釣る
- 自分の最大サイズを更新する

</Tab>
<Tab value="お金を稼ぎたい">

- たくさん釣ってコモン魚も売る
- 大きい魚を優先して売る
- エサやルアーIIIを使って効率を上げる

</Tab>
</Tabs>

<Callout type="info" title="図鑑が利用できない場合">
図鑑にはサーバー側の記録機能が必要です。「Fishing Journal is not accessible」と表示された場合は、プレイヤー側では直せないため、表示されたメッセージを添えて運営へ連絡してください。
</Callout>

## 🪱 エサを使う

```text
/emf applybaits
```

1. エサを用意する
2. エサを付けたい釣り竿を手に持つ
3. コマンドを入力してGUIからエサを選ぶ

エサは特定のレア度や魚を**少し狙いやすくする**アイテムです。付けたエサと残り回数は、釣り竿の説明欄で確認できます。

- 1本の釣り竿に複数種類のエサを付けられる場合があります
- 釣りをすると、使用したエサの残り回数が減ります
- エサを付けても、対象の魚が必ず釣れるわけではありません
- 大会中は公平性のため、エサが無効になる場合があります

## 🔥 溶岩釣り・奈落釣り

サーバー側で特殊釣りが有効になっている場合は、水以外でも釣りができます。どちらも普通の釣り竿を使います。

<Tabs items={['溶岩釣り', '奈落釣り']}>
<Tab value="溶岩釣り">

1. ネザーの溶岩へ釣り竿を投げる
2. 溶岩の上を近づく粒子と、食いつき音を待つ
3. 食いついた瞬間に右クリックして巻き上げる

溶岩へ入る必要はありません。安全な足場を作り、落下や炎上に注意して釣ろう。

</Tab>
<Tab value="奈落釣り">

1. ジ・エンドの島の端から、奈落へ向けて釣り竿を投げる
2. ウキが自分より数ブロック下まで落ちるのを待つ
3. 近づく粒子と食いつき音を確認し、右クリックで巻き上げる

転落防止の柵や足場を用意し、奈落へ身を乗り出さないようにしてください。

</Tab>
</Tabs>

<Callout type="warn" title="特殊釣りが始まらないとき">
粒子や食いつき音が出ない場合は、その機能・ワールド・プレイヤー権限がまだ有効になっていない可能性があります。何度も投げ直す前に運営へ確認してください。
</Callout>

## 🏆 釣り大会

現在、定期の釣り大会は開催していません。開催時は画面上部のボスバーやチャットで、競技内容と残り時間が案内されます。

大会では「最大サイズ」「釣った数」「合計サイズ」など、開催ごとに勝利条件が変わる場合があります。始まったら案内を読んでから釣りましょう。

| コマンド | 内容 |
|---|---|
| `/emf top` | 開催中の大会ランキングを見る |
| `/emf next` | 次の大会予定を確認する |
| `/emf toggle bossbar` | 大会ボスバーの表示を切り替える |

## 📦 釣ったアイテムの扱い

特殊な魚は、通常の魚アイテムと見た目が同じでも内部では別のアイテムです。

- 売るときはチェストショップではなく、`/emf shop`か`/emf sellall`を使う
- 調理・クラフト・設置・燃料への使用が防止されている場合があります
- 魚の見た目がプレイヤーヘッドでも、地面への設置や頭への装備はできません
- 魚ヘッドを保管できるのは、プレイヤーの持ち物・チェスト・樽だけです。ディスペンサー、ホッパー、シュルカーボックス、エンダーチェスト、プラグインGUIには入れられません
- 魚ヘッドはショップGUIへ移せないため、売る場合は `/emf sellall` を使用してください
- 記念品として残す魚は、誤売却を防ぐため別のチェストへ保管する
- インベントリがいっぱいだと受け取りにくいため、釣り前に空きを作る

## ❓ 困ったとき

| 困りごと | 確認すること |
|---|---|
| カスタム魚が釣れない | `/emf toggle fishing`で自分の釣り機能をONにし、水面とアタリのタイミングを確認 |
| 「この場所に魚がいない」と表示される | 漁場が枯渇中。ウキを8ブロック以上離すか、5分待ってから釣る |
| `/emf shop`が使えない | コマンドが候補に出なければ権限、画面は開くが売れなければ経済機能を運営へ確認 |
| 魚を売却枠へ置けない | EvenMoreFishで釣った魚か確認。通常の魚や別プラグインのアイテムは対象外の場合あり |
| 図鑑が開かない | 権限エラーか、サーバー側の記録機能が無効。表示メッセージを添えて運営へ連絡 |
| 図鑑に魚が増えない | 魚を釣り上げた後に開き直す。改善しなければ魚名と釣った時刻を運営へ連絡 |
| エサを付けられない | 対象の釣り竿をメインハンドに持ち、使用可能なエサが残っているか確認 |
| 溶岩・奈落で反応しない | 対象ワールドか確認。粒子・音が一度も出なければ機能の公開状況を運営へ確認 |

<Callout type="tip" title="最初の目標">
まず10匹釣る → `/emf shop`で1匹売る → レア魚を1匹釣る → 図鑑を1レア度埋める、の順で遊ぶと分かりやすいです。
</Callout>
