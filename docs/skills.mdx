ブロックを掘る・作物を収穫するといった **普段の行動でスキルが育ちます**。レベルが上がると **専用の能力** が解放され、採掘と農業では **お金も直接もらえます**。
</Callout>

## 📈 スキルとは？

CarrotCraft には **11種類のスキル** があります。特別な操作は要りません。いつも通り遊んでいれば経験値がたまり、勝手にレベルが上がります。

メニューは `/skills` で開けます。

| スキル | 上がる行動 | お金 |
|---|---|---|
| **採掘** | 石・鉱石を掘る | ⭕️ |
| **農業** | 作物を収穫する | ⭕️ |
| **伐採** | 原木・葉を壊す | ✖️ |
| **発掘** | 土・砂・砂利を掘る | ✖️ |
| **釣り** | 魚を釣る | ✖️ |
| **弓術** | 弓でモブを倒す | ✖️ |
| **格闘** | 近接でモブを倒す | ✖️ |
| **防御** | ダメージを受ける | ✖️ |
| **敏捷** | 落下ダメージを受ける | ✖️ |
| **錬金術** | ポーションを飲む・醸造する | ✖️ |
| **付与術** | エンチャント・金床・砥石を使う | ✖️ |

## 💰 収入のしくみ

**採掘と農業だけ**、ブロックを壊した瞬間にお金が入ります。掘った鉱石が価値ある物ほど多くもらえます。

| 掘ったもの | もらえる額 |
|---|---|
| 古代の残骸 | 20 CC |
| ダイヤ鉱石 | 10 CC |
| ラピス鉱石 | 3 CC |
| 金鉱石 | 2 CC |
| エメラルド鉱石 | 2 CC |
| 鉄鉱石 | 1.5 CC |
| 銅・レッドストーン鉱石 | 1 CC |
| 石炭鉱石 | 0.5 CC |
| 小麦・ビートルート | 0.5 CC |
| ネザーウォート | 1 CC |
| ニンジン | 0.4 CC |
| ジャガイモ | 0.35 CC |

石やネザーラック、原木・土などは **経験値だけ** でお金は入りません。

### 1日 10,000 CC を超えると効率が下がります

一部の人が掘り続けて経済を壊さないよう、**1日の収入が 10,000 CC を超えると、そこから先はだんだん取り分が減っていきます**。

| その日の収入 | 取り分 |
|---|---|
| 〜10,000 CC | **100%** |
| 15,000 CC | 50% |
| 20,000 CC | 20% |
| 25,000 CC | 10% |

<Callout type="info">
リセットは **日本時間の 0 時** です。翌日になればまた 100% に戻ります。普通に遊ぶぶんには 10,000 CC に届かないので、ほとんどの人は気にしなくて大丈夫です。
</Callout>

自分がいまどのくらいの取り分かは `/skills` のメニューで確認できます。

## ✨ レベルで解放される能力

<Steps>
<Step>
### 農業 — 自動植え替え（Lv5〜）

作物を収穫すると **自動でもう一度植え直します**。手作業で植え直す必要がなくなります。

発動する確率はレベルとともに上がり、**Lv5 で 25%、Lv100 で 100%** になります。抽選に外れたときは **種を消費しません**。
</Step>

<Step>
### 伐採 — 追加ドロップ（Lv1〜）

原木を壊したとき、**たまにもう1個多く落ちます**。最大 **Lv100 で 25%** まで上がります。幸運のエンチャントとは別枠なので、両方の効果が乗ります。
</Step>

<Step>
### 採掘 — 採掘速度上昇（Lv10 / 25 / 50）

一定確率で **採掘速度上昇** の効果が付きます。クールダウンは 10 分です。

| レベル | 効果 |
|---|---|
| Lv10 | 採掘速度上昇 I（15秒） |
| Lv25 | 採掘速度上昇 II（15秒） |
| Lv50 | 採掘速度上昇 II（25秒） |
</Step>

<Step>
### 格闘・防御・敏捷 — 常時強化

| スキル | 効果 | Lv100 での最大値 |
|---|---|---|
| **格闘** | 与ダメージ増加 | +5% |
| **防御** | 被ダメージ減少 | -5% |
| **敏捷** | 移動速度上昇 | +20% |

レベルに応じて少しずつ強くなります。
</Step>
</Steps>

## ⚠️ 対象にならないもの

不正に稼げてしまわないよう、いくつか除外しています。

- **自分で置いたブロック** — 置いて壊すの繰り返しでは上がりません
- **ピストンで動かしたブロック**
- **一度に大量に壊したとき** — 33個目からは経験値が 25% に下がります
- **名前を変えただけの金床作業** — 付与術は、エンチャントが増えたか耐久が回復したときだけ加算されます
- **エンチャントが付いていない砥石作業**

## ❓ よくある質問

**Q. スキルを上げないと損ですか？**

普通に遊んでいれば自然に上がります。意識して稼ぎに行かなくても大丈夫です。

**Q. レベルの上限は？**

上限はありません。ただしレベルが上がるほど必要な経験値は増えていきます。

**Q. お金はどこに入りますか？**

サーバーの所持金（CC）にそのまま入ります。`/bal` で確認できます。

**Q. 収入が減ってきた気がします**

その日 10,000 CC を超えていないか `/skills` で確認してください。日本時間 0 時にリセットされます。
