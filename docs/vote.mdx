## 🎁 投票ガチャの開け方

<Steps>
  <Step>
    **投票してキーを受け取る**

    投票するとインベントリに **投票キー（エコーシャード）** が届きます。
  </Step>
  <Step>
    **`/cc` でガチャを開く**

    ```
    /cc
    ```
  </Step>
  <Step>
    **ルーレットで抽選**

    ガチャは **ルーレット** で結果が決まります。
  </Step>
  <Step>
    **報酬を受け取る**

    当選アイテムは自動的にインベントリ／所持金に反映されます。
  </Step>
</Steps>

<Callout type="warn">
  インベントリが満杯だとアイテム報酬を受け取れない場合があります。開封前に空きを作っておきましょう。
</Callout>

## ⌨️ コマンド

| コマンド | 説明 |
|---------|------|
| `/vote` | 投票サイト一覧を表示 |
| `/cc` | 所持しているガチャキーを開封 |
