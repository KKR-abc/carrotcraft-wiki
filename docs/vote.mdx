## 🎁 投票ガチャの開け方

<Steps>
  <Step>
    **投票してキーを受け取る**

    投票するとインベントリに **投票ガチャキー** が届きます。
  </Step>
  <Step>
    右クリックでガチャを開く
  </Step>
  <Step>
    **ルーレットで抽選**

    ガチャは **ルーレット** で結果が決まります。
  </Step>
  <Step>
    **報酬を受け取る**

    当選アイテムは自動的にインベントリ／所持金に反映されます。
  </Step>
</Steps>

<Callout type="warn">
  インベントリが満杯だとアイテム報酬を受け取れない場合があります。開封前に空きを作っておきましょう。
</Callout>

## 📅 連続記録報酬
毎日投票を続けると、記録がたまります。記録をためていると、7日目•14日目•21日目•30日目に報酬がもらえます。

| 日数 | 報酬 |
| ------ | ------ |
| 7日目 | 10,000cc |
| 14日目 | 武器ガチャキーと装飾ガチャキー2個 |
| 21日目 | レアアイテムガチャキーと装飾ガチャキー3個 |
| 30日目 | 静寂の鍛冶型 |

<Callout type="info">
  保護チケットがあれば、その枚数だけ投票を忘れても記録が続きます。
  保護チケットは運営から配布されることがあります。
</Callout>

## 🎉 VoteParty

サーバー全体で投票数が1000増えるごとにサーバーにいるプレイヤー全員に**パーティーガチャキー**が配布されます。
パーティーガチャキーには他のガチャキーが含まれます。

## ⌨️ コマンド

| コマンド | 説明 |
|---------|------|
| `/vote` | 投票サイト一覧を表示 |
| `/cc` | 所持しているガチャキーを開封 |
| `/cc preview VoteCrate` | ガチャの中身一覧を見る（プレビュー） |
