<Callout type="info" title="Farmer's Delight とは">
人気料理MOD「**Farmer's Delight**」と、そのアドオン4本（**Ocean's Delight／Corn Delight／Delightful／Cultural Delights**）をプラグインとして移植したものです。**MODの導入や特別な設定は不要**で、Java版・統合版どちらのプレイヤーもそのまま遊べます。合計 **170種類以上** の料理・食材が追加されています。
</Callout>

## 📅 毎日あたらしいレシピが解放！

<Callout type="info">
アドオンの料理レシピ（寿司・トウモロコシ料理・砂漠のスイーツなど）は、**毎日 18:00 に2つずつ**自動で解放されていきます。解放の瞬間は **Discord に告知**が流れます。

- **解放前のレシピは作れません**（材料を先に集めて備えるのはアリ！）
- コアのFarmer's Delight料理と作業台クラフトは**最初から全部使えます**
</Callout>

## 🔪 調理器具の使い方

<Steps>
<Step>
### クッキングポット 🍲

**火の上**（焚き火・コンロなど）に鍋を置き、食材を右クリックで投入。レシピが揃うと自動で煮込みが始まり、完成したら**ボウルなどの器**を持って右クリックで取り分けます。
</Step>
<Step>
### まな板 + 包丁 🔪

まな板に食材を置き、**包丁（や斧・シャベル）で右クリック**して切り分けます。メインに道具・オフハンドに食材を持って右クリックでも一発で切れます。
</Step>
<Step>
### コンロ・スキレット 🔥

**コンロ**は上面に食材を置いて焼く調理台。鍋の熱源にもなります。**スキレット**はフライパンで、焚き火の上などで素早く焼けます。
</Step>
<Step>
### 竹マット 🎋

寿司・おにぎり用の調理台（**火は不要**）。マットに材料を右クリックで投入すると巻き上がり、完成品は**素手で右クリック**して受け取ります。作り方: 糸×2 ＋ 竹×4。
</Step>
<Step>
### かまど・燻製器・焚き火 ♨️

下ごしらえした切り身などは、バニラの**かまど・燻製器・焚き火**でそのまま焼けます（燻製器は2倍速、焚き火はゆっくり）。
</Step>
</Steps>

## 💧 お冷 — 満腹をリセット

「ごちそうを食べたら満腹＆満腹維持で、次の料理が食べられない…」というときのための**食べ歩きのお供**です。

| | |
|---|---|
| 作り方 | <Item name="水入りバケツ" /> ＋ <Item name="ガラス瓶" />×4 → <Item img="/items/cc/glass_of_water.png" name="お冷" />×4 |

| おまけ | バニラの**水入り瓶**を飲んでも軽く効く（満腹度 −1🍗＋満腹維持解除） |

## 💡 ちょっとした仕様

<Callout type="info">
- スープやシチューには**満腹を持続させる効果**（満腹維持）が付くものがあります。お腹を空かせたいときは**お冷**をどうぞ。
- **大皿・ポップコーンの箱**は右クリックで1人前ずつ取り分け。**食べかけを壊すと「残り◯人前」のアイテム**として戻ってくるので、置き直せば続きから食べられます（複製はできません）。
- ケーキやパイは設置して**包丁で1切れずつ**切り出せます。
- 一部の料理は本家MODの効果（再生・耐性・移動速度など）を再現しています。
</Callout>
