<Callout type="info" title="このページの読み方">
**統合版でも Java 版でも、MOD を入れずに**、ブラウザから近くの人と話せます。届く範囲はゲーム内のボイスチャット（Simple Voice Chat）と同じで、MOD を使っている人ともそのまま話せます。
</Callout>

## 🎙 Web 通話とは？

スマホや PC のブラウザで通話ページを開き、ゲームの中で近くにいる人と声で話せる機能です。Switch・PS・スマホ版などの統合版の人も使えます。

- マイクが無くても **聞くだけ** で参加できます
- 近くにいる人の一覧や位置は出ません。声が届いた人だけが画面に並びます

---

## 🪜 使い方

<Steps>
<Step>
### ゲームの中で `/vc` と打つ

ログイン用の **QR コードかリンク** が出ます（統合版は額縁の地図に QR が出ます）。
</Step>
<Step>
### QR かリンクを開いて「ログインする」

ブラウザでサイトにログインします。一度ログインすれば、しばらくはこの手順はいりません。
</Step>
<Step>
### 通話ページで「つなぐ」→ マイクを許可

近くの人と話せるようになります。マイクを許可しなくても、聞くだけでつながります。
</Step>
</Steps>

**2 回目からは**、サーバーに入った状態で [通話ページ](https://carrotcraft.net/ja/voice) を開いて「つなぐ」を押すだけです。

---

## 🎛 画面の見かた

- **マイク** … 押すとオン / ミュート
- **スピーカー** … 押すと聞く / 聞かない
- **押したら話す** … オンにすると、押している間だけ声が届きます（PC はスペースキーでも）
- **話している人** … 声が届いた人だけ並びます。人ごとに音量を変えたり、その人だけ聞かないようにもできます
- **グループ** … ゲーム内のボイスチャットと同じグループに入れます（合言葉つきのグループもあります）
- **設定** … マイク・スピーカーの端末、ノイズ抑制（AI）、左右で聞く、途切れる時のゆとり など

## ⌨️ ゲーム内のコマンド

| コマンド | 内容 |
|---|---|
| `/vc` | ログイン用の QR / リンクを出す |
| `/vc mute` | Web のマイクを切る / 戻す |
| しゃがみながら持ち替え（F） | Web のマイクを切る / 戻す |
| `/vc off` | Web 通話を切る |

---

## 📱 スマホ・ゲーム機の人へ

- **Switch・PS の人**は、スマホや PC で通話ページを開いてください
- **スマホでマイクラを遊んでいる人**は、マイクラを前に出すとマイクが止まる機種があります（特に iPhone）。**別の端末**で開くのがおすすめです
- 使えるブラウザ: Chrome・Edge・Firefox・Safari（iPhone は iOS 14.5 以降）

## 🎧 Simple Voice Chat（MOD）を使っている人へ

<Callout type="info" title="Web 通話につなぐと、そちらが優先されます">
MOD を入れている人が Web 通話につなぐと、**その間は MOD の声と耳がお休みになり、Web 通話の方で話し・聞きます**（二重に聞こえないようにするためです）。Web 通話を切れば、MOD の方が元どおり使えます。
MOD だけを使う人は今までどおりで、MOD の人と Web 通話の人はお互いに話せます。
</Callout>

## ❓ 困った時

| 症状 | 対処 |
|---|---|
| 「ゲームにログインしていません」と出る | サーバーに入った状態で「つなぐ」を押してください |
| 「コードが違うか、期限が切れています」と出る | `/vc` をもう一度打って、新しい QR / リンクで |
| サーバーを移動したら切れた | 通話ページでもう一度「つなぐ」を押してください |
| 自分の声が届かない | 画面の「マイク」がオンか、設定のマイクの端末が合っているか確認。スマホは別の端末で開くのがおすすめ |
| 声が途切れる | 設定の「途切れる時」を「ゆとり多め」に |
| 相手の声が大きい / 小さい | 「話している人」の欄で、その人だけ音量を変えられます |
